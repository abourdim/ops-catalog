## Phase 3: Add Kid-Friendly Detailed FAQ ★ HIGH PRIORITY
**~4-6 hr | HIGH | Script: `gen_faq.py`**

~296 apps have generic template FAQ. Expand from 4 → **8 kid-friendly Q&A pairs** (ages 10-16).

**8-question pattern**:
| # | Question type | Purpose |
|---|--------------|---------|
| Q1 | What is this? | Fun analogy intro |
| Q2 | How does it work? | Simple core concept |
| Q3 | What can I try? | Guided first activity |
| Q4 | What's the cool science? | Real-world connection |
| Q5 | Can I break it? | Challenge prompt |
| Q6 | What hardware do I need? | Links to Device Code |
| Q7 | Is it safe? | Privacy reassurance |
| Q8 | What's next? | Points to sibling apps |

**Location**: Help sidebar → FAQ tab → `<details class="help-item">` elements.
**i18n keys**: `faq_q1`/`faq_a1` through `faq_q8`/`faq_a8` in EN, FR, AR.
