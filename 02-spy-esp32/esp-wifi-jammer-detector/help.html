🚀 Start Here

Get up and running in 3 steps:

  1. Open index.html in any modern browser (Chrome, Firefox, Edge)
  2. Click "Enter HQ" on the splash screen (or "Skip" to browse without voting)
  3. Interact with the simulation — use the controls, click buttons, explore the canvas
  • For real hardware: open firmware.ino in Arduino IDE, select "ESP32 Dev Module" board, upload via USB

    • ❓ Frequently Asked Questions

    What is Wifi Jammer Detector?
    **1200+ lines of JS · 1100+ lines of CSS · Zero frameworks · Pure magic.**
    Do I need real hardware?
    No! The browser simulation works without any hardware. It simulates the real behavior so you can learn the concepts. If you have the hardware (ESP32), you can use the companion code files to run it for real.
    What languages are supported?
    The app supports English, French, and Arabic (with RTL). Click the language selector in Settings (gear icon) to switch. All UI, labels, FAQ, and instructions are fully translated.
    How do I change the theme?
    Open Settings (gear icon in the header). Choose from 8 themes: Midnight Ops, Cyber Neon, Desert Storm, Forest Recon, Riad, Medina, Blood Moon, and Arctic. Your choice is saved automatically.
    Can I use this for teaching/classroom?
    Absolutely! Each app is self-contained (no internet needed) and includes educational content, challenges, and How-To guides. Perfect for workshops, classrooms, and maker spaces.
    Which ESP32 board works?
    Any ESP32 dev board works (DevKitC, NodeMCU-32S, WROOM, etc). Make sure you have the ESP32 board package installed in Arduino IDE via Board Manager.

    ⚡ Hardware Setup
