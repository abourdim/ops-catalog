📚 USB HID Fundamentals

What is USB HID?

HID (Human Interface Device) is a USB class that allows keyboards, mice, and gamepads to communicate with computers. The ESP32-S2 can emulate a USB HID keyboard, sending keystrokes as if a real keyboard were typing.

Keystroke Injection Attacks

A USB Rubber Ducky exploits the trust computers place in USB keyboards. When plugged in, it is recognized as a keyboard and can type commands faster than any human, potentially opening terminals, downloading files, or changing settings.

DuckyScript Language

DuckyScript is a simple scripting language for keystroke injection. Commands include STRING (type text), DELAY (wait ms), GUI/WINDOWS (Win key), ENTER, TAB, and modifier combos like CTRL+ALT+DELETE.

Defense Strategies

Protect against HID attacks by: disabling USB ports via Group Policy, using USB device whitelisting, monitoring new HID device connections, employing USB firewalls, and training users to never plug in unknown USB devices.

🔌 ESP32-S2 Setup Guide
1

Hardware Requirements

ESP32-S2 board (e.g., ESP32-S2-Saola, Lolin S2 Mini). The S2 variant has native USB support which is essential for HID emulation. A USB-C cable is needed for both programming and deployment.

2

Arduino IDE Setup

Install ESP32 board support in Arduino IDE. Go to Tools > Board > ESP32S2 Dev Module. Enable USB CDC On Boot and set USB Mode to USB-OTG (TinyUSB). Install the TinyUSB library.

3

Flash the Firmware

Upload the USB HID keyboard firmware. The ESP32-S2 will appear as a standard USB keyboard when plugged into any computer. Use the DuckyScript parser to convert payloads into keypress sequences.

4

Deploy & Test

Write your payload in the editor above, export it, and flash to the ESP32-S2. Plug the device into a target machine. The payload executes immediately, typing keystrokes at machine speed. Always test on your own machines only!

⌨️ USB HID Protocol

USB HID (Human Interface Device) class allows peripherals to send input reports to a host. Keyboards send scancodes for each key press/release. The host OS trusts HID devices implicitly — no driver installation needed.

🔒 Keystroke Injection

Keystroke injection attacks exploit the implicit trust in USB keyboards. A malicious device can type commands to open terminals, download malware, or exfiltrate data — all within seconds of being plugged in.

🔌 ESP32-S2 as HID

The ESP32-S2 features a native USB peripheral (not USB-to-UART). With TinyUSB, it can enumerate as a standard USB keyboard. Combined with WiFi, it can receive payloads wirelessly for remote execution.

🛡️ USB Security

Defenses include: USB port lockdown policies, device whitelisting (USBGuard on Linux), monitoring for new HID enumeration events, physical USB port blockers, and user awareness training about rogue USB devices.
