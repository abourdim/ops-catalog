📚 How It Works

Motion Detection

The ESP32-CAM compares consecutive frames pixel-by-pixel. When the difference exceeds a threshold, motion is detected. In this simulation, mouse movement over the viewfinder triggers the same logic -- pixel regions near the cursor change, and the delta is measured.

XOR Image Encryption

Each captured image is encrypted using XOR with a pseudorandom key stream. XOR encryption is symmetric -- the same key encrypts and decrypts. Click on an encrypted thumbnail to decrypt and view it. This teaches students the basics of stream ciphers.

Auto-Delete Mechanism

Each capture has a self-destruct timer (default 30s). Once the countdown reaches zero, the image data is permanently erased from memory. Viewing the image does not reset the timer -- it is truly ephemeral. This teaches data lifecycle management.

Face Blur (Privacy)

When face blur is enabled, simulated face regions are pixelated before encryption. On a real ESP32-CAM, lightweight face detection (MTMNN) identifies bounding boxes and applies Gaussian blur before saving. This demonstrates privacy-preserving surveillance.

Arduino Sketch (Key Parts)

#include "esp_camera.h"
#include "FS.h"
#include "SD_MMC.h"

#define PIR_PIN 13
volatile bool motionDetected = false;

void IRAM_ATTR onMotion() {
  motionDetected = true;
}

void setup() {
  Serial.begin(115200);
  pinMode(PIR_PIN, INPUT);
  attachInterrupt(PIR_PIN, onMotion, RISING);
  initCamera();   // configure OV2640
  SD_MMC.begin(); // mount SD card
}

void loop() {
  if (motionDetected) {
    motionDetected = false;
    camera_fb_t *fb = esp_camera_fb_get();
    if (fb) {
      xorEncrypt(fb->buf, fb->len, SECRET_KEY);
      saveToSD(fb);
      esp_camera_fb_return(fb);
    }
  }
  deleteExpiredFiles(); // auto-cleanup
  delay(100);
}
🔐 Privacy, Ethics & Challenges

Ethical Surveillance

Surveillance technology carries responsibility. Always obtain consent before recording. Use encryption to protect captured data. Auto-delete ensures data minimization. Face blur protects identities when full video is not needed. These principles align with GDPR and Islamic ethics of respecting privacy (hurma).

Student Challenges

  • Modify the sensitivity to detect only large movements (filter out small changes).
  • Add a second encryption layer (double-XOR with different keys).
  • Implement a "panic button" that instantly deletes all captures.
  • Add timestamp watermark on each capture before encryption.
  • Create an alert system that logs motion events to the Activity Log with location info.

Real-World Applications

Wildlife cameras use motion detection to capture animal behavior without human presence. Security cameras in banks encrypt footage to prevent tampering. Hospital monitoring systems blur patient faces in corridor cameras. Understanding these systems helps students build responsible IoT devices.

What is Shadow Cam?

A simulated ESP32-CAM surveillance system with motion detection, XOR encryption, auto-delete, and face blur for learning about privacy-preserving surveillance.

How does motion detection work?

Move your mouse over the viewfinder canvas. The system compares pixel changes frame-by-frame. When changes exceed the sensitivity threshold, motion is detected and a capture is triggered.

How does encryption work?

Each capture is XOR-encrypted with a random key. XOR is a symmetric cipher -- the same operation encrypts and decrypts. Click an encrypted thumbnail to decrypt and view it.

What is auto-delete?

Each capture has a 30-second countdown. When it reaches zero, the image is permanently erased. This demonstrates ephemeral data storage and data lifecycle management.

👁 Motion Detection

Frame differencing compares pixel values between consecutive frames. High delta = motion. ESP32-CAM uses OV2640 sensor with JPEG compression.

🔒 XOR Encryption

XOR (exclusive or) flips bits using a key stream. plaintext XOR key = ciphertext. ciphertext XOR key = plaintext. Fast, simple, symmetric.

⏰ Auto-Delete

Ephemeral storage erases data after a time limit. Used in secure messaging (Signal), surveillance regulations, and GDPR compliance.

🔐 Privacy

Face blur, encryption at rest, auto-delete, and consent are pillars of ethical surveillance. Local-first processing prevents data leaks.
