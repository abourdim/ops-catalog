🛡️ Multi-Factor Auth

MFA combines: Knowledge factors (PIN, password), Possession factors (NFC tag, phone), and Inherence factors (fingerprint, face). Three-factor auth uses one from each category.

🧬 Biometric Security

Fingerprint sensors use capacitive, optical, or ultrasonic technology. False Accept Rate (FAR) measures how often an unauthorized print is accepted. Modern sensors: FAR < 0.001%.

📳 NFC Technology

NFC operates at 13.56 MHz with ~4cm range. ISO 14443 standard. Types: NFC-A (Mifare), NFC-B (Calypso), NFC-F (FeliCa). Each tag has a unique 4-10 byte UID.

💻 ESP32 Integration

ESP32 handles all three sensors via UART (fingerprint), I2C (NFC), and GPIO matrix (keypad). A servo motor physically locks/unlocks the vault door.
