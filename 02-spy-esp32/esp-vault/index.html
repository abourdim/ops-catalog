📚 Theory: Multi-Factor Authentication
🧬

Biometrics (Something You ARE)

Fingerprint, iris scan, face recognition. Unique biological traits that can't be easily copied. ESP32 capacitive sensors can detect basic touch patterns.

📳

NFC Token (Something You HAVE)

Near-Field Communication tags store unique IDs. The reader and tag must be within 4cm. ESP32 + PN532 module reads NFC/RFID at 13.56 MHz.

🔢

PIN Code (Something You KNOW)

Secret numeric code stored in your memory. Combined with other factors, even a simple PIN becomes very secure. ESP32 matrix keypad uses GPIO scanning.

🛡️

Why Multi-Factor?

Each factor alone can be compromised. Combining 3 different types makes unauthorized access exponentially harder. Banks, military, and data centers all use MFA.

💻 ESP32 Code

Arduino Sketch (Three-Factor Vault)

/*
 * ESP32 Three-Factor Vault
 * Fingerprint (AS608) + NFC (PN532) + Keypad + Servo lock
 *
 * Libraries:
 *   - Adafruit Fingerprint Sensor Library
 *   - Adafruit PN532 (I2C mode)
 *   - Keypad by Mark Stanley
 *   - ESP32Servo
 */

#include <Adafruit_Fingerprint.h>
#include <Wire.h>
#include <Adafruit_PN532.h>
#include <Keypad.h>
#include <ESP32Servo.h>

// --- Fingerprint on Serial2 ---
HardwareSerial fpSerial(2);
Adafruit_Fingerprint finger(&fpSerial);

// --- NFC on I2C ---
#define PN532_SDA 21
#define PN532_SCL 22
Adafruit_PN532 nfc(PN532_SDA, PN532_SCL);
uint8_t authorizedUID[] = {0xDE, 0xAD, 0xBE, 0xEF};

// --- 4x3 Keypad ---
const byte ROWS = 4, COLS = 3;
char keys[ROWS][COLS] = {
  {'1','2','3'},
  {'4','5','6'},
  {'7','8','9'},
  {'*','0','#'}
};
byte rowPins[ROWS] = {13, 12, 14, 27};
byte colPins[COLS] = {26, 25, 33};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

// --- Servo Lock ---
Servo lockServo;
#define SERVO_PIN 4
#define LOCKED_ANGLE   0
#define UNLOCKED_ANGLE 90

// --- Auth State ---
bool factorFP   = false;
bool factorNFC  = false;
bool factorPIN  = false;
String pinBuffer = "";
const String CORRECT_PIN = "1337";

void setup() {
  Serial.begin(115200);
  Serial.println("[VAULT] Booting three-factor vault...");

  // Fingerprint
  fpSerial.begin(57600, SERIAL_8N1, 16, 17);
  finger.begin(57600);
  if (finger.verifyPassword()) {
    Serial.println("[FP] Sensor found.");
  } else {
    Serial.println("[FP] Sensor NOT found!");
  }

  // NFC
  nfc.begin();
  nfc.SAMConfig();
  Serial.println("[NFC] PN532 ready.");

  // Servo
  lockServo.attach(SERVO_PIN);
  lockServo.write(LOCKED_ANGLE);
  Serial.println("[SERVO] Lock engaged.");

  Serial.println("[VAULT] Awaiting authentication...");
}

void loop() {
  if (!factorFP)  checkFingerprint();
  if (!factorNFC) checkNFC();
  if (!factorPIN) checkKeypad();

  if (factorFP && factorNFC && factorPIN) {
    unlockVault();
  }
  delay(50);
}

void checkFingerprint() {
  if (finger.getImage() != FINGERPRINT_OK) return;
  if (finger.image2Tz() != FINGERPRINT_OK) return;
  if (finger.fingerSearch() != FINGERPRINT_OK) return;

  Serial.printf("[FP] Match! ID=%d Conf=%d\n",
    finger.fingerID, finger.confidence);
  factorFP = true;
}

void checkNFC() {
  uint8_t uid[7];
  uint8_t uidLen;
  if (!nfc.readPassiveTargetID(
    PN532_MIFARE_ISO14443A, uid, &uidLen, 100)) return;

  if (uidLen == 4 &&
      memcmp(uid, authorizedUID, 4) == 0) {
    Serial.println("[NFC] Authorized tag!");
    factorNFC = true;
  } else {
    Serial.println("[NFC] Unknown tag.");
  }
}

void checkKeypad() {
  char key = keypad.getKey();
  if (!key) return;

  if (key == '#') {
    if (pinBuffer == CORRECT_PIN) {
      Serial.println("[PIN] Correct!");
      factorPIN = true;
    } else {
      Serial.println("[PIN] Wrong PIN.");
      pinBuffer = "";
    }
  } else if (key == '*') {
    pinBuffer = "";
    Serial.println("[PIN] Cleared.");
  } else {
    pinBuffer += key;
    Serial.printf("[PIN] %d digits\n", pinBuffer.length());
  }
}

void unlockVault() {
  Serial.println("[VAULT] === ACCESS GRANTED ===");
  lockServo.write(UNLOCKED_ANGLE);
  delay(10000);
  // Re-lock after 10s
  lockServo.write(LOCKED_ANGLE);
  factorFP = factorNFC = factorPIN = false;
  pinBuffer = "";
  Serial.println("[VAULT] Re-locked.");
}

❓ Help
What is multi-factor authentication?

MFA requires two or more verification methods from different categories: something you know (PIN), something you have (NFC card), and something you are (fingerprint).

Why not just use a password?

Passwords alone can be guessed, stolen, or brute-forced. MFA adds layers so even if one factor is compromised, the vault remains secure.

How does the fingerprint sensor work?

Capacitive sensors detect the ridges and valleys of your fingerprint. The ESP32 stores templates and compares scans using pattern-matching algorithms.

What is NFC?

Near-Field Communication allows two devices to exchange data within ~4cm range at 13.56 MHz. Each NFC tag has a unique ID that acts like a digital key.

Is my data private?

Yes. This app is a simulation. Everything runs locally in your browser. No data is sent anywhere.

🛡️ Multi-Factor Auth

MFA combines: Knowledge factors (PIN, password), Possession factors (NFC tag, phone), and Inherence factors (fingerprint, face). Three-factor auth uses one from each category.

🧬 Biometric Security

Fingerprint sensors use capacitive, optical, or ultrasonic technology. False Accept Rate (FAR) measures how often an unauthorized print is accepted. Modern sensors: FAR < 0.001%.

📳 NFC Technology

NFC operates at 13.56 MHz with ~4cm range. ISO 14443 standard. Types: NFC-A (Mifare), NFC-B (Calypso), NFC-F (FeliCa). Each tag has a unique 4-10 byte UID.

💻 ESP32 Integration

ESP32 handles all three sensors via UART (fingerprint), I2C (NFC), and GPIO matrix (keypad). A servo motor physically locks/unlocks the vault door.
