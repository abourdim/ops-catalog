🌐 Mesh Networking

A mesh network is a decentralized topology where each node relays data. If one path fails, data routes around it. ESP32 nodes create WiFi APs to form these meshes.

📶 WiFi AP Mode

In AP (Access Point) mode, the ESP32 creates its own WiFi network. Other devices connect directly — no router or internet needed. Range: ~50-100m outdoors.

🔐 AES-256 Encryption

AES-256 is a symmetric encryption standard used by governments. Each message is encrypted with a shared key, making interception useless without the key.

📡 Offline Communication

The entire mesh operates without internet. Messages hop node-to-node using WiFi direct connections. Untraceable, uncensorable, and fully autonomous.

🔒 Privacy

This simulator runs 100% in your browser. No data is sent anywhere. No tracking, no analytics. Local-first, privacy-first.
