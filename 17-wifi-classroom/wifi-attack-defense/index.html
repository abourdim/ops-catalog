❓ Help

        
What does this app do?
It simulates WiFi! 🔬 You get to experiment with WiFi signals in a safe sandbox.

        
How does it work?
The simulation runs in your browser. It models real WiFi signals so you can see what happens step by step.

        
What should I try first?
Press the main button and watch! 🎯 Then tweak the settings to see how different parameters change the results.

        
What's the real science?
This is real wireless networks! The same principles are used by professionals in the field. 🧪

        
Can I break it?
Try the Lab section! Push the parameters to extremes and see what happens. That's how scientists discover new things! 💡

        
What hardware do I need?
For the real version, you'll need a computer with Python 3. Check the 📦 Device Code section for ready-to-use firmware!

        
Is it safe to use?
Absolutely safe! 🛡️ Everything runs locally in your browser. No internet required, no data leaves your device.

        
What should I try next?
Try Wifi Escape Room and Wifi Security Audit! Each teaches something different. 🚀

      
What Am I Looking At?
The main area shows a live visualization.
The buttons control the simulation.
Below the main card, sections show detailed data.
The colored dot shows connection status.
