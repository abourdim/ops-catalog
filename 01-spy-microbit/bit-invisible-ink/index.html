❓ Help
What is Invisible Ink?

A simulation of self-destructing messages. Send a secret message that vanishes after the recipient reads it.

How does the self-destruct timer work?

Choose a delay (5s-60s). Once the message is opened, the countdown starts. When it reaches zero, the message is destroyed character by character.

What are read receipts?

Read receipts record the exact time the message was opened. This is logged so the sender knows when the message was viewed.

Is my data private?

Yes. Everything runs locally in your browser. No data is sent anywhere.

🔏 Ephemeral Messaging

Messages designed to disappear after being read. Used in apps like Snapchat and Signal for privacy.

🔥 Self-Destruct Timer

A countdown mechanism that triggers message deletion after a set time. Prevents long-term data retention.

👁️ Read Receipts

Confirmation that a message has been opened. Tracks when the recipient viewed the content.

🔍 Digital Forensics

The science of recovering and investigating digital data. Even "deleted" data can sometimes be recovered from memory or logs.
