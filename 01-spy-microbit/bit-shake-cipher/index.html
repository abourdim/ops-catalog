🔐 How It Works
1 The micro:bit accelerometer measures movement on 3 axes (X, Y, Z) — detecting tilts, shakes, and gestures in real time.
2 When you shake the device, the app records a sequence of acceleration values with timestamps, creating your unique shake pattern.
3 The pattern is used as a key to encrypt your message. A hash of the shake sequence scrambles the text so only the same pattern can unlock it.
4 To unlock, you reproduce the shake pattern. The app uses Dynamic Time Warping (DTW) to compare patterns, allowing slight timing variations while keeping security.

🏆 Challenges

🏅 Challenge 1 — Pattern Complexity

Record a pattern using at least 3 different movement directions (left-right, up-down, forward-back). Can you create a pattern that scores above 80% when you repeat it, but below 30% when someone else tries?

🏅 Challenge 2 — Brute Force Test

Lock a message with your pattern. Now try unlocking it with 5 completely random shake patterns. How many false positives occur? What does this tell you about the security of physical authentication?

🏅 Challenge 3 — False Positive Threshold

Experiment with the match threshold: at what percentage does the system become too lenient (letting wrong patterns through) vs. too strict (rejecting your own pattern)? Find the sweet spot between security and usability.

❓ Help
What is an accelerometer?

An accelerometer measures acceleration forces on 3 axes (X, Y, Z). The micro:bit has one built-in that detects tilts, shakes, and motion.

How does pattern authentication work?

Your unique shake pattern becomes a physical key. The app records acceleration data and uses it to encrypt messages. Only the same pattern can unlock them.

What is the micro:bit?

The BBC micro:bit is a pocket-sized computer with sensors (accelerometer, compass, light, temperature) that teaches coding and electronics.

Can I use this without a micro:bit?

Yes! The app simulates the accelerometer using mouse movement (desktop) or the DeviceMotion API (mobile). No hardware needed.

📊 Accelerometer

A sensor that measures proper acceleration (g-force) along 3 axes. The micro:bit accelerometer range is +/- 2g with 10-bit resolution.

🔐 Pattern Recognition

Algorithms that identify regularities in data. Here we use Dynamic Time Warping (DTW) to match shake patterns despite timing variations.

🛡️ Physical Authentication

Using physical actions (gestures, shakes, movements) as passwords. More intuitive than text passwords but requires pattern matching algorithms.

📡 micro:bit Sensors

The micro:bit v2 includes: accelerometer, magnetometer, temperature sensor, microphone, touch sensor, and light level sensor.
