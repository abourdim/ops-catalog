❓ Help
What happens when data is wiped?

Files are overwritten with random data, then deleted. This simulates a secure erase so data cannot be recovered.

What is the broadcast range?

The micro:bit radio has a range of about 70 meters. The alert is sent on all configured channels simultaneously.

What if I trigger a false alarm?

You have a countdown window to cancel. Press Cancel before the timer reaches zero to abort the sequence.

Can wiped data be recovered?

No. After a secure wipe with overwrite, the original data is gone forever. Always double-check before confirming.

📡 Emergency Broadcast

An emergency broadcast sends a distress signal on all available radio channels so any nearby device can receive the alert.

🗑️ Secure Erase

Secure erase overwrites data with random bytes before deletion, making recovery impossible even with forensic tools.

💀 Dead Man Switch

A dead-man switch triggers automatically when a user fails to perform a periodic action, used as a safety mechanism.

📻 micro:bit Radio Broadcast

The micro:bit radio module uses 2.4 GHz to send and receive messages between devices within range, on configurable groups.
