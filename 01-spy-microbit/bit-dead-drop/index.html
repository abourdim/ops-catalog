🏆 Challenge

What happens if you use the wrong key to decrypt?

You get garbled nonsense! XOR decryption with the wrong key produces random characters. This is why key secrecy is critical.

Can you intercept a drop without the key?

Yes, you can intercept the BLE broadcast, but you only see encrypted bytes. Without the key, the message remains unreadable.

Design a key exchange protocol for two agents.

Agents meet in person to agree on a key (out-of-band exchange). For digital exchange, use Diffie-Hellman: each agent generates a partial key, shares it publicly, then combines to create a shared secret.

❓ Help
What is a dead drop?

A dead drop is a spy technique where agents leave encrypted messages at hidden locations. This app simulates it using BLE.

What is BLE?

BLE (Bluetooth Low Energy) is a wireless protocol for short-range communication. micro:bit uses it to send small data packets.

How does XOR encryption work?

XOR compares each bit of your message with the key. Same bits give 0, different bits give 1. Apply XOR again with the same key to decrypt.

Can I use this with a real micro:bit?

This app is a simulation. To use real BLE, flash the MakeCode program onto two micro:bit v2 boards and pair them.

📡 BLE (Bluetooth Low Energy)

A wireless protocol designed for low power. Devices broadcast advertising packets that nearby scanners can detect. Range: 10-50m.

🔑 XOR Cipher

A symmetric cipher: plaintext XOR key = ciphertext. Ciphertext XOR key = plaintext. Simple but effective for learning.

📨 Dead Drop Protocol

Agent A encrypts and broadcasts. Agent B scans and decrypts. No direct connection needed — just shared airwaves and a shared key.

📻 micro:bit Radio

micro:bit v2 uses a 2.4GHz radio for BLE and custom radio groups. Packets are limited to ~20 bytes. RSSI measures signal strength.
