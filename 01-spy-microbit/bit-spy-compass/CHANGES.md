# Changelog

## v1.0 — Initial Release

### Features

- Animated compass rose canvas (250x250) with rotating needle, cardinal markers, and tick marks
- Real-time heading display in degrees (Orbitron font)
- 3 preset spy waypoints: Alpha Base (045), Bravo Tower (160), Charlie Bunker (290)
- Target selection dropdown and Navigate button
- Bearing difference calculation with live display
- Arrived detection: bearing diff below 5 degrees for 3 continuous seconds
- Arrived indicator with pulse animation
- Map canvas showing position dot, waypoint markers, trail line, and grid overlay
- Simulated heading drift with auto-steer toward target
- DeviceOrientation API integration for real magnetometer data
- Section A: How It Works (4 steps explaining magnetometer to navigation)
- Section B: Lab with interactive map view
- Section C: Challenge with 3 spy missions
- Help panel: FAQ (magnetometer, bearing vs heading, declination, micro:bit compass)
- Help panel: How-To (4-step guide)
- Help panel: Wiki (Magnetometer, Compass Bearing, Waypoint Navigation, micro:bit Compass)
- Full trilingual support (EN / FR / AR) with RTL
- All Workshop-DIY template features (8 themes, log, sound, easter eggs, pixel pet, etc.)
