🔐 How It Works
1

The micro:bit continuously samples the light sensor and accelerometer at regular intervals, reading ambient light (0-255) and motion magnitude.

2

Each reading is compared against user-defined thresholds. If light exceeds the light threshold OR motion exceeds the motion threshold, an intrusion is suspected.

3

When a threshold is breached while the alarm is armed, the system triggers an alert: the LED matrix flashes, the buzzer sounds, and the event is logged with a timestamp.

4

All triggered events are recorded in the alert history with the sensor type (light or motion), the value that caused the trigger, and the exact time. This log helps analyze patterns and reduce false alarms.

❓ Help
How does the light sensor work?

The micro:bit LED matrix doubles as a light sensor, measuring ambient light from 0 (dark) to 255 (bright). When a door opens, light floods in and the value spikes.

What is the accelerometer?

The accelerometer measures movement and tilt in 3 axes (X, Y, Z). We combine them into a single magnitude value. If someone touches or bumps the device, the magnitude spikes.

How do thresholds work?

A threshold is a boundary value. If a sensor reading crosses the threshold, the alarm triggers. Lower thresholds = more sensitive (more false alarms). Higher = less sensitive.

How can I reduce false alarms?

Increase the thresholds, reduce noise in the environment, or add a delay before triggering (require multiple readings above threshold). Real systems use averaging and debouncing.

💡 Light Sensors

Light sensors (photoresistors, photodiodes, or LED-based) convert light intensity into electrical signals. The micro:bit uses its LED matrix in reverse to detect ambient light levels from 0 to 255.

📐 Accelerometer

An accelerometer measures acceleration forces in 3 axes. At rest, it reads gravity (~1g). Movement adds forces. The magnitude sqrt(x2+y2+z2) gives overall motion intensity.

📊 Threshold Detection

Threshold detection compares sensor values against a set boundary. Values above trigger actions. Hysteresis (different on/off thresholds) prevents rapid toggling near the boundary.

🔒 Security Systems

Modern security systems combine multiple sensors (PIR motion, door contacts, vibration, cameras) with logic controllers. They use zones, delays, and communication protocols to detect and report intrusions.
