💡 Light Sensors

Light sensors (photoresistors, photodiodes, or LED-based) convert light intensity into electrical signals. The micro:bit uses its LED matrix in reverse to detect ambient light levels from 0 to 255.

📐 Accelerometer

An accelerometer measures acceleration forces in 3 axes. At rest, it reads gravity (~1g). Movement adds forces. The magnitude sqrt(x2+y2+z2) gives overall motion intensity.

📊 Threshold Detection

Threshold detection compares sensor values against a set boundary. Values above trigger actions. Hysteresis (different on/off thresholds) prevents rapid toggling near the boundary.

🔒 Security Systems

Modern security systems combine multiple sensors (PIR motion, door contacts, vibration, cameras) with logic controllers. They use zones, delays, and communication protocols to detect and report intrusions.
