What is ARP and why is it vulnerable?

ARP maps IP addresses to MAC addresses on local networks. It is vulnerable because it has no authentication — any device can claim any IP-to-MAC mapping.

How does a MITM attack work via ARP spoofing?

The attacker sends fake ARP replies claiming the gateway's IP belongs to their MAC. Victims then route all traffic through the attacker, who can read or modify it.

How can you defend against ARP spoofing?

Use static ARP entries, enable Dynamic ARP Inspection (DAI) on switches, use encrypted protocols (HTTPS, VPN), and monitor for duplicate IP-MAC mappings.

📡 ARP

Address Resolution Protocol. Maps Layer 3 (IP) to Layer 2 (MAC). Operates on the local network only. Stateless and unauthenticated.

🏷️ MAC Address

48-bit hardware address burned into network cards. Format: AA:BB:CC:DD:EE:FF. First 3 bytes identify the vendor (OUI).

🕵️ MITM

Man-in-the-Middle attack. Attacker positions between victim and gateway to intercept, read, or modify all traffic.

🛡️ DAI

Dynamic ARP Inspection. Switch feature that validates ARP packets against a DHCP snooping database to prevent spoofing.
