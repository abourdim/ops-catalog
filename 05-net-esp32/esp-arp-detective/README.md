# esp-arp-detective — Workshop DIY

Monitor ARP tables and spot MITM attacks. Learn how ARP spoofing works and how to detect it.

## What You'll Learn

- How ARP maps IP to MAC addresses
- ARP spoofing and man-in-the-middle attacks
- Network topology visualization
- Spoof detection techniques

## Quick Start

Open `index.html` in any modern browser. No server needed.

## Features

- ARP table display with IP-to-MAC mappings
- Network topology canvas visualization
- Spoof alert indicator with MITM visualization
- Inject Spoof button to simulate attacks
- 3 security challenges with reveal answers
- 8 themes (6 dark + 2 light Islamic)
- Trilingual: EN / FR / AR (RTL)
- PWA-ready
