🏆 Challenge

Why are captive portals a security risk?

Evil twin attacks: an attacker creates a fake WiFi with a captive portal to harvest credentials. Users trust the familiar login page and enter real passwords.

How does the ESP32 force users to the portal page?

The ESP32 runs a DNS server that redirects ALL domains to its own IP, plus an HTTP server serving the portal page. Any URL the user visits shows the portal.

Design a secure captive portal authentication system.

Use HTTPS for the portal, validate credentials server-side, implement rate limiting, use session tokens, and never store passwords in plaintext.

It lets you see how computer networks talk to each other! 🌐 Like X-ray vision for internet traffic.

The simulation shows real network protocols — the rules that computers follow to send data across the internet.

🚪 Captive Portal

A network access control method. Users must interact with a web page before accessing the internet.

📶 Access Point

ESP32 in SoftAP mode creates its own WiFi network. Clients connect and receive an IP via DHCP.

😈 Evil Twin

A rogue access point that mimics a legitimate one. Combined with a captive portal, it can steal credentials.

📋 DHCP

Dynamic Host Configuration Protocol. Automatically assigns IP addresses to devices joining the network.
