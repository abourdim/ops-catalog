🏆 Challenge

What happens when you kill a critical bridge node?

The mesh splits into two partitions. Messages between partitions fail until the node heals or new links form.

Why does BFS find the shortest path?

BFS explores all neighbors at distance 1 before distance 2, guaranteeing the first path found is the shortest in an unweighted graph.

How can a mesh network survive multiple node failures?

Redundancy! Each node connects to multiple neighbors, creating alternate paths. The more connections, the more resilient the mesh.

❓ Help
What is a mesh network?

A mesh network connects devices to each other, not to a central router. Each node can relay messages for others, creating a resilient web.

What is ESP-MESH?

ESP-MESH is Espressif's protocol for ESP32 chips. It builds a self-organizing, self-healing mesh over WiFi.

How does self-healing work?

When a node fails, neighbors detect the loss and reroute traffic through alternate paths automatically.

Is my data private?

Yes. Everything runs locally in your browser. No data is sent anywhere.

🕸️ Mesh Topology

Each node connects to nearby neighbors. Messages hop from node to node using BFS routing.

🔍 BFS Routing

Breadth-First Search explores all neighbors before going deeper, finding the shortest path in unweighted graphs.

🔄 Self-Healing

When nodes fail, the mesh detects broken links and finds alternate routes. Recovered nodes rejoin automatically.

📡 ESP-MESH

ESP-MESH supports up to 1000 nodes. Each node can be both a station and an AP simultaneously.
