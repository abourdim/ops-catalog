🏆 Challenge

What is the difference between TCP and UDP?

TCP is connection-oriented with error checking and retransmission. UDP is connectionless — faster but unreliable. TCP = phone call, UDP = postcard.

Why is ARP important for network attacks?

ARP maps IP addresses to MAC addresses. ARP spoofing lets attackers redirect traffic through their machine (man-in-the-middle).

How can you detect a packet storm on a real network?

Monitor bandwidth usage, check for unusual packet rates, use IDS/IPS systems, and look for traffic patterns that deviate from baseline.

🔵 TCP

Transmission Control Protocol — reliable, ordered, connection-oriented. Used for web, email, file transfer.

🟢 UDP

User Datagram Protocol — fast, connectionless, no delivery guarantee. Used for streaming, gaming, DNS.

🟡 ICMP

Internet Control Message Protocol — used for ping, traceroute, and network diagnostics.

🔴 ARP

Address Resolution Protocol — maps IP addresses to MAC addresses on local networks.
