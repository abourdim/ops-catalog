# esp-network-cartographer — How To Use

## Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)

## Lab Walkthrough

### Step 1: Start Scanning
Click "Start Scan" to begin discovering simulated WiFi, BLE, and ESP-NOW devices.

### Step 2: Read the Map
Devices appear as colored circles on the radar map. Blue = WiFi, Green = BLE, Orange = ESP-NOW. Larger circles = stronger signal.

### Step 3: Observe BLE Flickering
BLE devices simulate advertising intervals by flickering on and off — just like real BLE behavior.

### Step 4: Check the Device List
The scrollable list shows each device with its name, MAC address, RSSI, and protocol type.

### Step 5: Analyze Signals
Open the Signal Analysis section for average RSSI and the strongest device name.

### Step 6: Try the Challenges
Test your knowledge about BLE advertising, RSSI-distance relationships, and ESP-NOW.

## What Each Step Teaches

| Step | Concept |
|------|---------|
| 1 | Multi-protocol radio scanning |
| 2 | RSSI and signal-based distance estimation |
| 3 | BLE advertising behavior |
| 4 | Device identification by MAC and name |
