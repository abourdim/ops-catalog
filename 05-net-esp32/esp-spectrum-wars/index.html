🏆 Challenge

Why does adding more devices slow everyone down?

WiFi is a shared medium. Devices must take turns (CSMA/CA). More devices = more waiting, more collisions, more retransmissions.

What is the hidden node problem?

Two devices that cannot hear each other both transmit to the same AP, causing collisions at the AP. RTS/CTS protocol helps solve this.

How do modern WiFi standards reduce collisions?

WiFi 6 uses OFDMA to divide channels into sub-channels, allowing multiple devices to transmit simultaneously. MU-MIMO sends to multiple devices at once.

What is spectrum contention?

When multiple devices try to use the same radio frequency, they must share it. More devices = less bandwidth each.

What causes WiFi collisions?

Two devices transmitting at the same time on the same channel. The signals interfere and both packets are corrupted.

How does CSMA/CA work?

Carrier Sense Multiple Access / Collision Avoidance: listen before transmitting, wait a random time if busy, then send.

📡 RF Spectrum

WiFi uses 2.4 GHz and 5 GHz bands. Each band has multiple channels. Overlapping channels cause interference.

🔄 CSMA/CA

Collision avoidance protocol. Devices sense the channel, wait if busy, then transmit with random backoff to avoid collisions.

🔀 OFDMA

WiFi 6 feature: Orthogonal Frequency Division Multiple Access. Splits channels into sub-channels for simultaneous multi-device access.

📡 MU-MIMO

Multi-User MIMO. AP uses multiple antennas to communicate with several devices simultaneously, increasing total throughput.
