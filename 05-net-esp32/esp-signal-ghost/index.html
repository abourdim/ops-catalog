Why does MAC spoofing confuse network equipment?

Switches and routers use MAC address tables (CAM tables) to forward packets. Flooding with fake MACs fills these tables, causing traffic to be broadcast to all ports.

How can networks defend against MAC flooding?

Port security limits MACs per port. 802.1X authenticates devices. Dynamic ARP inspection validates ARP packets. Rate limiting restricts new device connections.

What is the difference between MAC randomization and MAC flooding?

MAC randomization (used by phones for privacy) changes your MAC periodically. MAC flooding deliberately generates thousands of fake MACs to attack the network infrastructure.

🏷️ MAC Address

A 48-bit hardware address (6 bytes) that uniquely identifies a network interface. Format: XX:XX:XX:XX:XX:XX.

📋 CAM Table

Content Addressable Memory table in switches. Maps MAC addresses to physical ports. Limited capacity (typically 8K-128K entries).

🌊 MAC Flooding

Overflowing the CAM table forces the switch to broadcast all traffic, enabling sniffing on all ports.

🛡️ Port Security

Switch feature limiting MACs per port. Violations can shut down the port or drop traffic.
