🏆 Challenge

Why are hidden SSIDs not truly hidden?

Hidden SSIDs are omitted from beacon frames, but are still visible in probe responses, association requests, and data frames. Any WiFi analyzer can detect them.

What makes XOR encryption weak?

XOR with a short key repeats, making it vulnerable to frequency analysis. If the plaintext is known, the key is trivially recovered.

How could you make a dead drop more secure?

Use AES encryption, MAC address filtering, time-limited AP activation, and one-time download tokens that delete files after retrieval.

Pro Tips

Did You Know?

Common Mistakes

📡 Hidden Access Points

Hidden APs don't broadcast their SSID in beacons but respond to directed probe requests.

🔑 XOR Encryption

A symmetric cipher where plaintext XOR key = ciphertext. Simple but educational.

📦 Dead Drop Protocol

Agent hides an ESP32 running a hidden AP. Another agent scans, connects, downloads, and decrypts.

📡 ESP32 SoftAP

ESP32 can run as a WiFi access point (SoftAP) with configurable SSID visibility and authentication.
