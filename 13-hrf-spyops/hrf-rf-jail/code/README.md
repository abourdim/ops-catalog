# RF Jail — Device Code

> RF Jail — Virtual Faraday Cage

## Files

### `micropython/main.py`
- **Hardware:** BBC micro:bit V2
- **How to run:** Flash via [Mu Editor](https://codewith.mu/) or [microbit.org](https://python.microbit.org/)

### `arduino/main.ino`
- **Hardware:** ESP32 Dev Module
- **How to run:** Upload via [Arduino IDE](https://www.arduino.cc/en/software) with ESP32 board package

### `python/main.py`
- **Hardware:** Any PC with Python 3
- **How to run:** Run with `python3 main.py`
