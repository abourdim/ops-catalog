What is a WiFi canary and how does it differ from WIDS?

A canary is a passive, lightweight sensor that watches for specific changes (new APs, channel changes, deauths). WIDS is a full enterprise system with more features but higher complexity.

What suspicious WiFi changes should trigger an alert?

New unknown APs, SSID spoofing (same name different MAC), channel changes, deauth floods, and sudden signal strength changes.

Why is passive monitoring better than active scanning for security?

Passive monitoring is invisible to attackers (no probe requests), consumes less power, and cannot be detected or evaded.
