# 📉 SDR Noise Floor — Workshop DIY

Analyze noise floor, thermal noise, noise figure, MDS, and dynamic range for SDR receivers.

## Features

- **Noise floor spectrum** with real-time display and averaging
- **Waterfall display** showing noise patterns over time
- **Noise calculations**: kTB, NF, noise floor, MDS, SNR, dynamic range
- **Noise histogram**: amplitude distribution with Gaussian overlay
- **Adjustable parameters**: temperature, bandwidth, NF, signal level, averaging
- **Test signal injection**: see signals emerge from noise floor
- **Trilingual**: English, Francais, Arabic (RTL)
- **8 themes** with Islamic art inspiration

## How It Works

1. Set receiver parameters (temperature, bandwidth, noise figure)
2. Adjust test signal level and averaging depth
3. Press Start to see live noise floor analysis
4. Watch signal emerge from noise as you increase signal level or averaging
