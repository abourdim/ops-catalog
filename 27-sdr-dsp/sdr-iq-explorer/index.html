🔧 IQ Correction

Automatic IQ imbalance correction estimates gain and phase offset and compensates in real-time.

📖 IQ Theory

I/Q (In-phase/Quadrature) representation is fundamental to SDR:

  • Complex signal: s(t) = I(t) + jQ(t)
  • Magnitude: |s| = sqrt(I² + Q²)
  • Phase: φ = atan2(Q, I)
  • IQ imbalance causes image frequency leakage
  • Lissajous pattern reveals phase relationships
