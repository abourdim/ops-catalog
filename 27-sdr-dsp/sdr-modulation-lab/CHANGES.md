# SDR Modulation Lab — Changelog

## v1.0 — 2025-01-01
- Initial release
- 7 modulation types: AM, DSB-SC, SSB, FM, BPSK, QPSK, 16-QAM
- Live time-domain, spectrum, and constellation displays
- Coherent and envelope demodulation
- Adjustable SNR with noise simulation
- Signal metrics: BER, EVM, bandwidth, power
- Trilingual i18n (EN/FR/AR with RTL)
- 8 themes with Islamic art inspiration
