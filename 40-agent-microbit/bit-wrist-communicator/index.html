🔐 Tap Code

Tap code is a cipher used to encode messages by tapping pairs of numbers that correspond to a row and column in a 5x5 grid. It was famously used by prisoners of war to communicate secretly through walls.

📐 Polybius Square

The Polybius square is a device invented by the ancient Greek historian Polybius for fractionating plaintext characters so they can be represented by a smaller set of symbols. Each letter is identified by its row and column in a 5x5 grid.

🤚 Haptic Communication

Haptic communication uses touch to convey information. From Braille to vibration-based wearables, haptic systems allow non-visual, non-auditory message transmission — perfect for covert or accessible communication.

🏛️ POW Communication

During the Vietnam War, American POWs used tap code extensively to communicate between cells. They tapped on walls, used broom handles, and even coughed in patterns to spell out messages without guards detecting them.
