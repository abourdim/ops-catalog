🔐 How It Works
1

Sensors are placed around the perimeter of the area to protect. Each sensor node monitors its surroundings using motion, infrared, or trip-wire detection.

2

Each sensor covers a zone — a segment of the perimeter. Together they form a continuous fence line with overlapping coverage.

3

When someone crosses the boundary, the nearest sensor detects the breach and triggers an alert. The system identifies which zone was compromised.

4

The alert is sent wirelessly to the central unit (your screen). The operator sees the breach location in real-time and can respond immediately.

❓ Help
What is the Invisible Fence?

A perimeter security simulation using virtual micro:bit sensors. Place sensors on a map to create a monitored boundary and detect intruders.

How do I place sensors?

Click "Add Sensor" then click anywhere on the map canvas. Each sensor has a detection radius shown as a colored circle.

How does breach detection work?

When a simulated intruder enters a sensor's detection radius, that sensor triggers and the zone status changes to BREACH.

Can I test coverage gaps?

Yes! Activate the fence to see coverage. Dark areas are gaps. Use the intruder simulation to find weak spots in your perimeter.

🔲 Perimeter Security

Perimeter security protects the boundary of an area using physical or electronic barriers. Sensors detect unauthorized entry and trigger alerts.

📡 Sensor Networks

Wireless sensor networks use distributed nodes that communicate to monitor an environment. Each node covers a zone and reports to a central controller.

🗺️ Zone Mapping

Zone mapping divides a perimeter into segments, each monitored by one or more sensors. Overlapping zones ensure complete coverage without gaps.

🚨 Breach Detection

Breach detection identifies when an unauthorized entity crosses the perimeter. Sensors compare readings against thresholds to trigger immediate alerts.
