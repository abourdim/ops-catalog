# CHANGES — bit-micro-beacon-trail

## v1.0 — 2025-03-18

### Added
- Interactive trail map canvas (800x350) with grid background
- Drop Beacon: click-to-place and auto-placement modes
- Follow Trail: animated position arrow navigating beacon-to-beacon
- Clear Trail: reset all beacons and follower state
- RSSI simulation with path loss model (A=-59 dBm, n=2.0) and noise
- Beacon list: scrollable numbered entries with ID, timestamp, RSSI
- Trail stats: live beacon count and total distance
- Pulsing beacon dots with glow animation on canvas
- Dashed trail line connecting beacons in order
- Green arrow follower with rotation toward next beacon
- Section A (How It Works): 4-step BLE beacon trail explanation
- Section B (Lab): 4 hands-on exercises for trail creation and analysis
- Section C (Challenge): 3 challenges (loop trail, missing beacons, coded trail)
- Help panel: FAQ (4 items), How-To (4 steps), Wiki (BLE Beacons, iBeacon, Path Tracking, Indoor Nav)
- Full i18n: English, French, Arabic with all beacon-specific keys
- All template features preserved: 8 themes, RTL, log, toast, sound, easter eggs, pixel pet, matrix rain, ghost cursors, whisper mode, breathing guide, music reactive, AR mode, AI chat
