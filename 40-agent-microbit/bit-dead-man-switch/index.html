❓ Help
What is a Dead Man's Switch?

A safety device that triggers an alert if the operator stops moving or becomes incapacitated. Used in trains, heavy machinery, and lone-worker systems.

How does the micro:bit detect motion?

The micro:bit uses its built-in accelerometer to measure acceleration on X, Y, and Z axes. Movement magnitude is calculated from all three.

What happens when the alert triggers?

The system plays an alarm sound, logs the event with a timestamp, and simulates broadcasting an SOS signal over radio.

Can I adjust the sensitivity?

Yes. Use the timeout slider (5-60 seconds) to set how long inactivity is allowed before the alert fires.

💀 Dead Man's Switch

A fail-safe mechanism requiring continuous operator input. If input stops, the system assumes the operator is incapacitated and triggers a safety response.

⏱️ Watchdog Timers

A hardware or software timer that must be periodically reset. If not reset in time, it triggers a corrective action — used in embedded systems to detect crashes.

📡 Inactivity Detection

Using sensors (accelerometer, gyroscope) to detect lack of movement. Thresholds define what counts as motion vs. stillness.

🛡️ Safety Systems

Engineered systems designed to prevent harm: automatic shutoffs, emergency alerts, redundant controls, and fail-safe defaults protect operators and bystanders.
