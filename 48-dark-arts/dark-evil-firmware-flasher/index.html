📖 Theory & Notes

Educational simulation of firmware security analysis. Demonstrates how malicious firmware modifications work to help build better defenses.

  • Firmware = software embedded in hardware devices (routers, IoT, USB)
  • Backdoors allow unauthorized remote access to compromised devices
  • Checksum verification detects unauthorized firmware modifications
  • Secure boot chains prevent loading of tampered firmware images
