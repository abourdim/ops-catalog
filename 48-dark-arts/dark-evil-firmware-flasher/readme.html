Quick Start

  1. Open index.html in any modern browser
  2. Or run python3 -m http.server 8080 in this folder
  3. Flash firmware.ino to ESP32 via Arduino IDE
  4. Run python3 hackrf.py with RTL-SDR/HackRF connected
