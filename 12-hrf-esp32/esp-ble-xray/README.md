# 💙 BLE X-Ray — Workshop DIY v1.2

BLE frequency hopping visualizer — 1600 hops/sec across 40 channels.

## Features
- 2.4 GHz waterfall with animated channel hopping
- 40-channel histogram (data + advertising channels)
- Simulated BLE device list with RSSI
- Adjustable hop speed (1x/4x/16x)
- Adaptive Frequency Hopping visualization
- i18n EN/FR/AR, 8 themes, activity log
