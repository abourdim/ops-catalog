# 🔍 RF IoT Audit — Workshop DIY v1.2

WiFi+BLE+ESP-NOW simultaneous protocol audit simulator.

## Features
- 3-panel concurrent view: WiFi, BLE, ESP-NOW
- Live device lists with RSSI for each protocol
- Protocol distribution timeline chart
- Security audit report with warnings
- Simulated concurrent scanning
- i18n EN/FR/AR, 8 themes, activity log
