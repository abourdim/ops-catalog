📖 About Phased Arrays

A phased array antenna consists of multiple radiating elements whose individual phases are controlled to steer the beam without physical movement.

By adjusting the phase of each element, the combined radiation pattern can be steered to any direction. A Raspberry Pi can control phase shifters via SPI or I2C.

This simulator shows how element count, spacing, and phase progression affect beam direction, gain, and sidelobe levels.

❓ Help
What is a phased array?

Multiple antenna elements with individual phase control to steer the beam electronically.

How does beam steering work?

By varying the phase between elements, the beam direction changes without moving the antenna.

What affects beam width?

More elements and wider spacing produce narrower beams with higher gain.
