📚 How It Works
  1. Client types a URL and sends an HTTP request. First stop: the DNS server to resolve the domain name to an IP address.
  2. The router forwards the packet through the network, choosing the best path between nodes.
  3. The firewall inspects the packet. If the request is allowed, it passes through; if blocked, it's dropped.
  4. The web server receives the request, processes it, and sends the HTTP response back through the same path.

🌐 DNS

The Domain Name System is the phonebook of the internet. It translates domain names to IP addresses so browsers can load resources.

📄 HTTP/HTTPS

HTTP is the foundation of data communication on the web. HTTPS adds encryption via TLS for secure communication.

🛡️ Firewalls

Firewalls monitor network traffic and enforce security policies. They can be hardware devices or software running on a server.

🔀 Routing

Routing is the process of selecting paths in a network to send data packets from source to destination.
