📚 How It Works
  1. The sender wraps the message in 3 encryption layers (like an onion), one key per relay node.
  2. Relay 1 (Guard) peels the first layer using its key, revealing the next relay address.
  3. Relay 2 (Middle) peels the second layer, revealing the exit relay address.
  4. Relay 3 (Exit) peels the final layer, revealing the original plaintext message.

Pro Tips

Did You Know?

Common Mistakes

🧅 Tor Network

Tor (The Onion Router) is a free overlay network for anonymous communication. Traffic is routed through 3+ relays.

🔐 XOR Cipher

XOR encryption applies a key bitwise. A XOR K = encrypted, encrypted XOR K = A. Simple but demonstrates the layering concept.

📡 Relay Types

Guard relay: first hop (knows sender). Middle relay: intermediate hop. Exit relay: last hop (knows destination).

🛡️ Anonymity

No single relay knows both the origin and destination. This separation of knowledge provides anonymity.
