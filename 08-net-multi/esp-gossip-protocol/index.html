📚 How It Works
  1. One node is "seeded" with data (infected). It knows information that others do not.
  2. Each round, every infected node randomly picks a neighbor and shares (gossips) the data.
  3. The neighbor becomes infected with a probability based on the spread percentage.
  4. After enough rounds, all nodes converge — everyone has the data. This is epidemic dissemination.

💬 Gossip Protocols

Gossip (epidemic) protocols achieve eventual consistency by random peer-to-peer information exchange. Simple, scalable, and fault-tolerant.

🦠 Epidemic Models

SI (Susceptible-Infected) model: once a node is infected, it stays infected and keeps spreading. SIR adds recovery.

📊 Convergence

Gossip converges in O(log N) rounds for N nodes, making it very efficient for large networks.

🔧 Applications

Used in Apache Cassandra, Amazon DynamoDB, Bitcoin network, and Kubernetes cluster management.
