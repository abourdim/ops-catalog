🔐 How It Works
1

Nodes maintain a neighbor table listing all directly connected peers and their link quality.

2

Each node sends periodic heartbeat signals. If a neighbor misses several heartbeats, it is marked as failed.

3

When a failure is detected, the network recalculates alternative routes using a BFS flooding algorithm.

4

New paths are established through surviving nodes, restoring full connectivity — the network has healed itself.

❓ Help
What is Mesh Rescue?

A simulation that teaches how mesh networks automatically recover when nodes fail. Build, break, and heal networks!

How do I kill a node?

Click "Kill Node" then click any active (green) node on the canvas. It will turn red and its connections will break.

What does healing do?

The heal function uses BFS to find alternative routes through surviving nodes, restoring network connectivity.

Is my data private?

Yes. Everything runs locally in your browser. No data is sent anywhere.

🔄 Self-Healing Networks

A self-healing network detects node or link failures and automatically reconfigures to maintain connectivity without human intervention.

💓 Heartbeat Protocol

Nodes periodically send heartbeat signals to neighbors. Missing heartbeats indicate a failed node, triggering route recalculation.

🔀 Redundant Routing

Mesh networks maintain multiple paths between nodes. When one path fails, traffic is rerouted through alternate paths automatically.

🛡️ Fault Tolerance

A fault-tolerant system continues operating even when components fail. Redundancy and self-healing are key strategies.
