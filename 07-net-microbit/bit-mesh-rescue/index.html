What does this app do?

It lets you see how computer networks talk to each other! 🌐 Like X-ray vision for internet traffic.

How does it work?

The simulation shows real network protocols — the rules that computers follow to send data across the internet.

What should I try first?

Start a scan and watch the packets fly! 📡 Each colored packet is a different type of network message.

What's the real science?

This is how the entire internet works! TCP/IP, DNS, ARP — these protocols power every website you visit. 🌍

Can I break it?

Try the Lab section! See what happens when you inject bad packets or flood the network. That's network security! 🛡️

What hardware do I need?

For the real version, you'll need BBC micro:bit V2. Check the 📦 Device Code section for ready-to-use firmware!

Is it safe to use?

Totally safe! 🛡️ This is a simulation — no real network traffic. Everything stays in your browser.

🔄 Self-Healing Networks

A self-healing network detects node or link failures and automatically reconfigures to maintain connectivity without human intervention.

💓 Heartbeat Protocol

Nodes periodically send heartbeat signals to neighbors. Missing heartbeats indicate a failed node, triggering route recalculation.

🔀 Redundant Routing

Mesh networks maintain multiple paths between nodes. When one path fails, traffic is rerouted through alternate paths automatically.

🛡️ Fault Tolerance

A fault-tolerant system continues operating even when components fail. Redundancy and self-healing are key strategies.
