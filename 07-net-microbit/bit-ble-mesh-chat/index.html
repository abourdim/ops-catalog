🔐 How It Works
  1. Each node discovers its neighbors within BLE range and builds a local neighbor table.
  2. When a message is sent, it is tagged with a TTL (Time-To-Live) value that limits how far it can travel.
  3. Each relay node decrements the TTL by 1 and forwards the message to all its neighbors (flooding).
  4. The destination receives the message if reachable, or the message expires when TTL reaches zero.

❓ Help
What is mesh networking?

Mesh networking connects devices in a web where each node can relay data for others. If one path fails, messages find another route.

What is TTL (Time-To-Live)?

TTL limits how many times a message can be relayed. Each hop decrements the TTL by 1. When it reaches 0, the message is dropped to prevent infinite loops.

What is the difference between flooding and routing?

Flooding sends a message to all neighbors blindly. Routing uses a table to forward messages along the best path. This app uses flooding for simplicity.

What is the BLE range?

BLE (Bluetooth Low Energy) typically has a range of 10-30 meters indoors. In this simulation, nodes connect if they are within a configurable distance on the canvas.

🕸️ Mesh Networks

A mesh network is a topology where each node relays data for the network. It provides redundancy and self-healing capabilities.

⏱️ TTL (Time-To-Live)

TTL is a counter attached to each message that decrements at every hop. It prevents messages from circulating forever in the network.

🌊 Flooding Algorithm

Flooding is a simple routing strategy where every node re-broadcasts received messages to all neighbors. Simple but uses more bandwidth.

📶 BLE Mesh Standard

Bluetooth Mesh is an official standard (Mesh Profile 1.0) enabling many-to-many communication over BLE, used in IoT, smart buildings, and sensor networks.
