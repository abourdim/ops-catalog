🔐 How It Works
1 Alice encrypts the message with Bob's shared key using XOR cipher.
2 The encrypted message is sent through one or more relay nodes.
3 The relay forwards the data but cannot read it — it only sees encrypted gibberish.
4 Bob receives the cipher text and decrypts it with the same shared key.

❓ Help
What is Micro VPN?

A simulation of an end-to-end encrypted relay network using micro:bit. Learn how VPN tunnels protect your data!

What is XOR encryption?

XOR is a simple cipher where each character is combined with a key character using the exclusive-or operation. It is symmetric: the same key encrypts and decrypts.

What is a relay node?

A relay forwards data between two endpoints. With encryption, the relay cannot read the contents — it only passes encrypted bytes along.

What is a Man-in-the-Middle attack?

An attacker intercepts communication between two parties. With E2E encryption, the attacker sees only gibberish. Without it, they can read everything.

🔐 E2E Encryption

End-to-end encryption ensures only the sender and receiver can read the message. Intermediate nodes (relays, ISPs, routers) see only cipher text.

🛡️ VPN Tunneling

A VPN creates an encrypted tunnel between two points. All traffic inside the tunnel is protected from eavesdropping, even on untrusted networks.

📡 Relay Nodes

Relays forward encrypted packets between endpoints. They enable communication across networks but cannot decrypt the payload without the key.

🕵️ Man-in-the-Middle

A MITM attack intercepts traffic between two parties. E2E encryption defeats this because the attacker lacks the decryption key.
