❓ Help
What is Radio Sniffer?

A simulation that teaches how radio frequency scanning works using micro:bit radio groups.

How do I scan channels?

Use the channel slider to pick a channel, then click "Start Scan" or "Auto Scan" to sweep all channels.

What are the 84 channels?

micro:bit radio uses groups 0-83. Each group is a separate communication channel on the 2.4GHz band.

Is this real radio traffic?

No. This is a simulation for learning. Real packet sniffing requires actual micro:bit hardware.

📡 Radio Spectrum

The radio spectrum is the range of electromagnetic frequencies used for wireless communication. micro:bit uses the 2.4GHz ISM band.

🔍 Packet Sniffing

Packet sniffing is the practice of capturing data packets transmitted over a network or radio channel for analysis.

📻 micro:bit Radio Groups

micro:bit supports 84 radio groups (0-83). Devices on the same group can communicate. Each group uses a different frequency offset.

🔀 Frequency Hopping

Frequency hopping rapidly switches the carrier frequency among many channels. It improves security and reduces interference.
