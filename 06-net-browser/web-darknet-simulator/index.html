📚 Onion Routing Reference

Onion routing encrypts data in multiple layers. Each relay peels one layer, knowing only the previous and next hop. Guard nodes know the client IP but not the destination. Exit nodes see the destination but not the client. This provides anonymity through separation of knowledge.

🛡️ Anonymity Risks

Timing attacks correlate entry and exit traffic patterns. Traffic analysis can deanonymize users over time. Malicious exit nodes can intercept unencrypted traffic. Guard node compromise reveals client IPs.
