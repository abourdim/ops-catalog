# HOWTO — Darknet Simulator

## 1. View the Onion Network
The canvas shows relay nodes: Guard (entry), Middle, and Exit relays.

## 2. Build a Circuit
Click "Build Circuit" to create a 3-hop onion circuit through random relays.

## 3. Host a Hidden Service
Click "Create Hidden Service" to simulate hosting a .onion service.

## 4. Connect to Hidden Service
Click "Connect" to route traffic through the circuit to the hidden service.

## 5. Try Deanonymization
Open Section C and run the "Timing Attack" demo to see how traffic analysis can deanonymize users.

## 6. Change Language/Theme
Open Settings to customize language and theme.
