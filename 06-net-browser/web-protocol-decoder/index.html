📚 OSI Model Layers

The OSI model has 7 layers: Physical, Data Link, Network, Transport, Session, Presentation, Application. Network packets are encapsulated layer by layer. Ethernet wraps IP, IP wraps TCP/UDP, and TCP/UDP wraps application data like HTTP.

🔢 Hex Encoding Guide

Hexadecimal (base-16) represents binary data using digits 0-9 and letters A-F. Each hex pair represents one byte (8 bits). For example, 0x48 0x54 0x54 0x50 spells "HTTP" in ASCII. Network analyzers like Wireshark display raw packet data in hex.

What is Protocol Decoder?

A packet autopsy tool that decodes hex data into protocol layers with animated visualization.

Is this real packet analysis?

No, this is a simulation for educational purposes. Sample packets are pre-built to demonstrate decoding.
