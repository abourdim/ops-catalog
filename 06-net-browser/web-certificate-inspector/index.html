        📚 Certificate Fields Reference
        

          

            
TLS certificates contain fields like Subject (domain owner), Issuer (CA that signed it), Validity (not-before/not-after dates), Public Key Algorithm (RSA, ECDSA), Serial Number, and extensions like Subject Alternative Names (SAN). The chain of trust goes from Leaf (your site) through Intermediate CA(s) to the Root CA trusted by your browser.

          

        

      


      
      

        🛡️ Security Best Practices
        

          

            
Always verify certificate chains before trusting a connection. Check for expired certificates, self-signed certs, weak algorithms (SHA-1, MD5), and mismatched domain names. Use Certificate Transparency logs to detect rogue certificates. Pin certificates for critical services.

          

        

      


      
      

        🧪 Chain Comparison Tool
        

          

            
Compare certificate chains side by side to understand trust differences between valid, expired, and self-signed certificates.

What does this app do?
It lets you see how computer networks talk to each other! 🌐 Like X-ray vision for internet traffic.

        
How does it work?
The simulation shows real network protocols — the rules that computers follow to send data across the internet.

        
What should I try first?
Start a scan and watch the packets fly! 📡 Each colored packet is a different type of network message.

        
What's the real science?
This is how the entire internet works! TCP/IP, DNS, ARP — these protocols power every website you visit. 🌍

        
Can I break it?
Try the Lab section! See what happens when you inject bad packets or flood the network. That's network security! 🛡️

        
What hardware do I need?
For the real version, you'll need a computer with Python 3. Check the 📦 Device Code section for ready-to-use firmware!

        
Is it safe to use?
Totally safe! 🛡️ This is a simulation — no real network traffic. Everything stays in your browser.
