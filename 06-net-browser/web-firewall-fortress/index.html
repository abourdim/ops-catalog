📚 How Firewalls Work

Firewalls filter network traffic based on rules. Each rule specifies criteria (source IP, destination IP, port, protocol) and an action (ALLOW or DENY). Packets are checked against rules in order. The first matching rule determines the action.

🎯 Common Attack Patterns

Common attacks include port scanning (probing many ports), SYN floods (overwhelming with connection requests), and payload injection (sending malicious data). Firewalls block these by matching source patterns, rate limiting, and deep packet inspection.

⚡ Advanced Rules

Advanced rules use wildcards (*) to match any value. You can create rules for specific port ranges, block entire IP ranges, or allow only specific protocols. Order matters: rules are checked top to bottom.
