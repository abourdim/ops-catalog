📚 Blockchain Concepts

A blockchain is a linked list of blocks. Each block contains data, a timestamp, its own hash, and the previous block's hash. If any block is modified, its hash changes, breaking the link to the next block. This makes the chain tamper-evident. Mining involves finding a nonce that produces a hash meeting a difficulty target.

🛡️ Cryptographic Hashing

SHA-256 produces a fixed 256-bit hash from any input. Even tiny changes produce completely different hashes (avalanche effect). Hashes are one-way: you cannot reverse-engineer the input from the hash. This is fundamental to blockchain security.

🧪 Mining Settings

Adjust mining difficulty. Higher difficulty = more leading zeros required = longer mining time.
