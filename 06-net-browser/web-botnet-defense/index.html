📚 Botnet Architecture

A botnet is a network of compromised computers controlled by a C2 (Command & Control) server. Bots receive commands to launch DDoS attacks, send spam, steal data, or mine cryptocurrency. Botnets use various C2 architectures: centralized (single server), P2P (peer-to-peer), or domain flux (fast-changing DNS).

🛡️ Defense Strategies

Defend against botnets by: monitoring network traffic for anomalies, isolating compromised nodes, sinkholing C2 domains, deploying intrusion detection systems, and coordinating with ISPs to take down C2 infrastructure.

🧪 C2 Trace-Back

Trace the command chain from bots back to the C2 server.
