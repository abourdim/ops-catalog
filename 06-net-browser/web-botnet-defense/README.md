# Botnet Defense — Command & Control

**Workshop DIY — Net Browser Collection**

Simulated botnet: compromised nodes, C2 server, DDoS attacks. Isolate bots and trace the C2.

## Features

- Network canvas with C2 server and bot nodes
- Infection spread animation
- DDoS target visualization
- Isolation tool to quarantine bots
- Trace-back path to C2 (Section C)
- Trilingual i18n (EN / FR / AR with RTL)
- 8 themes, activity log, sound effects

## Files

| File | Description |
|------|-------------|
| `index.html` | Layout with botnet canvas, infection controls, defense tools |
| `script.js` | Botnet simulation, infection propagation, DDoS, defense actions |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html` in a browser. Watch infection spread, launch DDoS, isolate bots, trace C2.
