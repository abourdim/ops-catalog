📚 How Port Scanning Works

Port scanning sends probe packets to a range of ports on a target host. An open port responds (SYN-ACK for TCP), a closed port sends RST, and filtered ports give no response (blocked by firewall). Tools like Nmap use these responses to map services.

🔢 Common Ports Reference

Well-known ports: 22 (SSH), 25 (SMTP), 53 (DNS), 80 (HTTP), 110 (POP3), 143 (IMAP), 443 (HTTPS), 3306 (MySQL), 3389 (RDP), 5432 (PostgreSQL), 8080 (HTTP Proxy).

⚠️ Vulnerability Assessment

After scanning, assess open ports for known vulnerabilities. Outdated services, default credentials, and unnecessary open ports are common security risks.
