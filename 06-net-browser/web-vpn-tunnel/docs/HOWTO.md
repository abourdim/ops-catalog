# HOWTO — VPN Tunnel

## 1. Enter a Message
Type a message in the input field (e.g. "Hello Server").

## 2. Toggle Encryption
Use the encryption toggle to enable or disable VPN encryption.

## 3. Send the Message
Click "Send" to watch the message travel through the tunnel with animation.

## 4. Compare With/Without VPN
Send the same message with encryption on and off to see the difference.

## 5. Explore Encryption Algorithms
Open Section C for details about AES, RSA, and other encryption algorithms used in VPNs.

## 6. Change Language/Theme
Open Settings to switch between EN/FR/AR and choose from 8 themes.
