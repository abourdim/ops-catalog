# 🔒 VPN Tunnel — Encryption Visual

**Workshop DIY — Net Browser Collection**

Watch data get encrypted, tunneled through a VPN, and exit safely. Toggle encryption on/off to see the difference.

## Features

- Tunnel canvas showing Alice to VPN Server to Internet to Destination
- Data display at each stage (plaintext / encrypted / plaintext)
- Toggle encryption on/off to compare
- Animated packet traveling through the tunnel
- Visual encryption transformation effect
- Section C: Encryption Algorithms panel
- Trilingual i18n (EN / FR / AR with RTL)
- 8 themes, activity log, sound effects

## Files

| File | Description |
|------|-------------|
| `index.html` | Layout: main card (tunnel canvas + controls) + 3 sections |
| `script.js` | i18n, tunnel visualization, encryption simulation, animation |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html`. Type a message, toggle encryption, and click Send to watch the VPN tunnel in action.
