# DNS Odyssey — Resolution Journey

**Workshop DIY — Net Browser Collection**

Watch full recursive DNS resolution step by step. Animated canvas shows browser to resolver to root to TLD to authoritative.

## Features

- Animated DNS resolution canvas with step-by-step visualization
- Domain input with resolve button
- TTL cache display showing cached records
- Resolution history in Section C
- Trilingual i18n (EN / FR / AR with RTL)
- 8 themes, activity log, sound effects

## Files

| File | Description |
|------|-------------|
| `index.html` | Layout: main card + 3 sections + help/settings panels |
| `script.js` | i18n, DNS resolution simulation, canvas animation, caching |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html` in a browser. Enter a domain, click Resolve, watch the step-by-step DNS resolution.
