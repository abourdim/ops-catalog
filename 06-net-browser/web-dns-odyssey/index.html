📚 DNS Record Types

DNS uses different record types: A (IPv4 address), AAAA (IPv6), CNAME (alias), MX (mail server), NS (name server), TXT (text data), SOA (start of authority), and PTR (reverse lookup). Each record has a TTL that controls caching duration.

🛡️ DNS Security

DNSSEC adds cryptographic signatures to DNS records to prevent spoofing. DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT) encrypt DNS queries to protect privacy.
