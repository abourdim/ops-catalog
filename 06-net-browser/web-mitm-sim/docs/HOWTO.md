# HOWTO — MITM Simulator

## 1. Send a Message
Type a message and click Send to have Alice send it to Bob.

## 2. Enable Eve's Intercept
Toggle "Eve Intercept" ON to let Eve read messages passing through the network.

## 3. Enable Encryption
Toggle "Encryption" ON to encrypt messages. Eve can no longer read the content.

## 4. Compare Results
Send messages with different combinations of intercept and encryption to see the effects.

## 5. Defense Strategies
Open Section C for information about HTTPS, certificate pinning, and other MITM defenses.

## 6. Change Language/Theme
Open Settings to switch between EN/FR/AR and choose from 8 themes.
