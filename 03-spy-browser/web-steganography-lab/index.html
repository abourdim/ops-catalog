🎓 How LSB Steganography Works

Each pixel in an image has Red, Green, and Blue channels, each stored as an 8-bit value (0-255).

The Least Significant Bit (LSB) is the rightmost bit. Changing it shifts the value by at most 1 — invisible to the human eye.

For example: 142 = 10001110. Changing the LSB to 1 gives 143 = 10001111. Visually identical!

We convert each character of the message to 8 bits, then store each bit in the LSB of successive pixel channels (R, G, B).

❓ Help
What is steganography?

Steganography is the art of hiding secret data inside ordinary-looking media (like images) so that no one suspects it exists.

What is LSB encoding?

LSB (Least Significant Bit) encoding stores secret data in the least important bits of pixel color values. Changing a value by 1 is invisible to the eye.

Is my data safe?

Yes. Everything runs locally in your browser. No images or messages are uploaded anywhere.

Can I use my own images?

Yes! Click "Upload Image" to use any PNG or JPEG. Larger images can hold longer messages.

🖼️ Steganography

The practice of concealing messages within non-secret data. Used since ancient Greece — now digital!

💻 LSB Encoding

Each pixel has RGB channels (0-255). The LSB can be flipped without visible change, storing 3 bits per pixel.

📊 PSNR

Peak Signal-to-Noise Ratio measures image quality. Above 40 dB means the change is practically invisible.
