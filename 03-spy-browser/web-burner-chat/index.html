📚 How E2E Encryption Works

End-to-end encryption ensures only the sender and recipient can read messages. The server (or relay) sees only encrypted data. Keys are exchanged using Diffie-Hellman key agreement.

🔥 Ephemeral Messaging

Ephemeral messages are designed to disappear after being read or after a set timer. This reduces the digital footprint and protects against data breaches.
