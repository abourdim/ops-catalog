# 🔎 Metadata Detective — Photo Forensics

**Workshop DIY — Spy Browser Collection**

Extract hidden EXIF data from photos. Visualize GPS coordinates on a map. Run forensic analysis to detect tampering.

## Features

- 4 sample photos with full simulated EXIF data (20+ fields each)
- GPS coordinate visualization on canvas map
- Forensic analysis: timestamp consistency, software detection, tampering alerts
- Trilingual i18n (EN / FR / AR with RTL)
- 8 themes, activity log, sound effects

## Files

| File | Description |
|------|-------------|
| `index.html` | Layout: main card + 3 sections (EXIF ref, Privacy, Forensics) + help panel |
| `script.js` | i18n, simulation engine, EXIF extraction, GPS map, forensic analysis |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html` in a browser. Select a photo, click Extract Metadata, explore the EXIF table and GPS map.
