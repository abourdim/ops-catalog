# 🎣 Phishing Trainer — Spot the Fake

**Workshop DIY — Spy Browser Collection**

Score points by identifying phishing attempts. 12 realistic email/URL scenarios with detailed explanations.

## Features

- 12 scenarios (emails and URLs, mix of real and phishing)
- Scoring system with accuracy tracking
- Detailed red flag explanations for each scenario
- Statistics panel
- Trilingual i18n (EN / FR / AR with RTL), 8 themes

## Files

| File | Description |
|------|-------------|
| `index.html` | Main card + 3 sections (Red Flags, Protection, Statistics) + help |
| `script.js` | i18n, 12 scenarios, scoring, explanations, statistics |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html`. Read each scenario, click Legitimate or Phishing, learn from explanations.
