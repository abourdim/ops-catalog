# 🗺️ Network Map — Spy Graph

**Workshop DIY — Spy Browser Collection**

Map peer connections as a spy network with force-directed graph layout, node discovery, and message routing.

## Features

- Force-directed graph layout with physics simulation
- Up to 20 agents (NATO phonetic alphabet names)
- Drag nodes, auto-layout with repulsion/spring forces
- Send encrypted messages between nodes (animated)
- Discover hidden connections
- Network analysis: centrality ranking, density, most connected node
- Canvas-based real-time rendering
- Trilingual i18n (EN / FR / AR with RTL), 8 themes

## Files

| File | Description |
|------|-------------|
| `index.html` | Main card + 3 sections (Theory, Encryption, Analysis) + help |
| `script.js` | i18n, force-directed graph, node interaction, analysis |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html`. Click Add Agent, Send Message, Discover Node. Drag nodes to rearrange.
