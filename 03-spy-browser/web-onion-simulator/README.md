# 🧅 Onion Simulator — Tor Visualization

**Workshop DIY — Spy Browser Collection**

Watch encrypted messages bounce through Tor relay nodes with 3-layer encryption peeling off at each hop.

## Features

- Animated onion routing through Entry/Middle/Exit nodes
- 3-layer encryption visualization (Base64 simulation)
- Country-based relay selection from 12 countries
- Custom circuit builder
- Canvas-based network visualization
- Trilingual i18n (EN / FR / AR with RTL), 8 themes

## Files

| File | Description |
|------|-------------|
| `index.html` | Main card + 3 sections (Routing, Encryption, Circuit Builder) + help |
| `script.js` | i18n, Tor simulation, encryption layers, canvas animation |
| `style.css` | Shared template styles (unchanged) |
| `manifest.json` | PWA manifest |

## Quick Start

Open `index.html`. Type a message, click Send through Tor, watch the routing animation.
