❓ Help
What is this app?

An all-in-one cryptography learning toolkit. Explore classical and modern ciphers, encrypt/decrypt messages, and learn how crypto works step by step.

What is the difference between symmetric and asymmetric?

Symmetric ciphers (Caesar, Vigenere, AES, OTP) use the same key for encryption and decryption. Asymmetric (RSA) uses a public key to encrypt and a private key to decrypt.

Is the RSA here real?

No. This is a simplified RSA with small primes for learning. Real RSA uses 2048+ bit keys. Never use this for actual security.

Is my data private?

Yes. Everything runs locally in your browser. No data is sent anywhere.

What is steganography?

Steganography hides secret messages inside ordinary-looking data like images. Unlike encryption, the goal is to hide the existence of the message itself.

What is a one-time pad?

A one-time pad is the only mathematically proven unbreakable cipher. The key must be truly random, as long as the message, and never reused.

Caesar Cipher

Shifts each letter by a fixed number. Used by Julius Caesar (~58 BC). Easily broken by frequency analysis or brute force (only 25 possible keys).

Vigenere Cipher

Polyalphabetic cipher using a keyword. Each letter of the key determines a different shift. Resisted cryptanalysis for 300 years ("le chiffre indechiffrable").

RSA Algorithm

Asymmetric encryption based on the difficulty of factoring large numbers. Uses public/private key pairs. Foundation of modern internet security (TLS/SSL).

AES Encryption

Advanced Encryption Standard. Symmetric block cipher used worldwide. Our demo uses XOR-based simulation to teach the core concept of key mixing.

One-Time Pad

The only mathematically unbreakable cipher when used correctly: truly random key, same length as message, never reused. Used by spies during the Cold War.

Steganography

The art of hiding messages in plain sight. Our tool uses LSB (Least Significant Bit) encoding to hide text in image pixels, invisible to the human eye.
