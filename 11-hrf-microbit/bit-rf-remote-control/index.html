📡 Radio Protocols

Radio protocols define how devices communicate wirelessly. They specify frequency, modulation, frame format, and error handling rules.

📦 Frame Structure

A frame is the basic transmission unit. It typically includes a preamble for synchronization, an address to identify the receiver, a command or data payload, and a checksum for integrity.

🔢 Checksums

Checksums are computed values appended to a frame so the receiver can verify data integrity. XOR checksum is the simplest: XOR all bytes together.

🛡️ Error Detection

Error detection lets the receiver know if data was corrupted during transmission. Common methods include parity bits, CRC, and checksums.
