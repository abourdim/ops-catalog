# How-To: Pi NAS Vault

## Getting Started

1. Open `index.html` in any modern browser.
2. Click **Unlock Vault** to decrypt the storage.
3. Storage stats and file browser become available.

## Storage Monitor

- Shows 4 network shares with sizes and file counts.
- Disk usage bar visualizes capacity.

## File Browser

- Lists files and directories in the vault root.
- Icons distinguish files from folders.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
