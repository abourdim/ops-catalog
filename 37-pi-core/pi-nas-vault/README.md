# 💾 Pi NAS Vault

**Workshop-DIY Pi Core Learning Lab**

Encrypted NAS server. Simulates LUKS-encrypted storage with shares, file browser, and disk monitoring.

## Features

- LUKS encryption lock/unlock simulation
- Storage monitor with 4 network shares
- File browser with directory listing
- Disk usage bar and statistics
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Unlock Vault**
3. Browse shares and files
