# 🔐 Pi VPN Gateway

**Workshop-DIY Pi Core Learning Lab**

WireGuard VPN server and gateway manager. Simulates peer management, tunnel config, and traffic monitoring.

## Features

- Connected peers list with status and traffic
- TX/RX bandwidth counters
- WireGuard tunnel configuration display
- Peer QR code generation
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Start VPN**
3. Monitor peer connections and traffic
