# 🎙️ Pi Radio Recorder

**Workshop-DIY Pi Core Learning Lab**

24/7 spectrum recording and archiving station on Raspberry Pi. Simulates continuous IQ recording with live spectrum, disk monitoring, and browsable archive.

## Features

- Live spectrum analyzer canvas
- Recording timer with disk usage monitoring
- Data rate and file count tracking
- Archive table with past recordings
- Trilingual UI (EN/FR/AR) with RTL support
- 8 themes, activity log, sound effects

## Quick Start

1. Open `index.html` in a browser
2. Click **Record** to start capturing
3. Watch spectrum display and disk usage
4. Browse the recording archive

## Tech Stack

Vanilla JS, HTML5 Canvas, zero dependencies.
