# How-To: Pi iGate Digipeater

## Getting Started

1. Open `index.html` in any modern browser.
2. Click **Start iGate** to begin APRS operation.
3. Stations will appear on the map as packets are received.

## Station Map

- Color-coded icons: Cyan=vehicles, Green=digipeaters, Yellow=weather, Orange=hikers.
- Stations move in real-time as position updates arrive.

## Packet Monitor

- Raw APRS packets displayed with timestamps.
- Shows callsign, path, position, and comment fields.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
