# 📍 Pi iGate Digipeater

**Workshop-DIY Pi Core Learning Lab**

APRS iGate and digipeater infrastructure node. Simulates position tracking, packet decoding, and station mapping on 144.390 MHz.

## Features

- Interactive station map canvas with color-coded icons
- APRS packet monitor with raw decoded data
- iGate RX and Digi TX counters
- APRS-IS connectivity status
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Start iGate**
3. Watch stations appear on the map
