# How-To: Pi Tor Router

## Getting Started

1. Open `index.html` in any modern browser.
2. Click **Start Tor** to connect to the Tor network.
3. A circuit is built automatically through 3 relay nodes.

## Circuit Monitor

- Shows the path: You -> Guard -> Middle -> Exit -> Internet.
- Click **New Circuit** to build a fresh path.

## Traffic Stats

- Bandwidth graph shows data throughput over time.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
