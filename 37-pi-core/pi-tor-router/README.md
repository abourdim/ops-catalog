# 🧅 Pi Tor Router

**Workshop-DIY Pi Core Learning Lab**

Transparent Tor proxy for network anonymization. Simulates circuit building, bandwidth monitoring, and exit node selection.

## Features

- Circuit visualization showing Guard, Middle, and Exit nodes
- Bandwidth graph canvas
- Exit node country display
- New circuit builder
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Start Tor** to connect
3. Watch circuits build and bandwidth flow
