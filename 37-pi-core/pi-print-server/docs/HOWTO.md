# How-To: Pi Print Server

## Getting Started

1. Open `index.html` in any modern browser.
2. Type text in the input field and click **Print**.
3. Jobs appear in the queue and process automatically.

## Print Queue

- Shows all pending and completed jobs.
- Status changes from "printing" to completed.

## Test Page

- Click **Test Page** to send a test print job.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
