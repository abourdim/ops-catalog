# 🖨️ Pi Print Server

**Workshop-DIY Pi Core Learning Lab**

Thermal receipt printer server. Simulates print queue, paper monitoring, and ESC/POS configuration.

## Features

- Print queue with job tracking
- Paper level and printer status monitoring
- Text input for custom print jobs
- Test page button
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Type text and click **Print**
3. Watch jobs process through the queue
