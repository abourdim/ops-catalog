# 🍯 Pi Honeypot Server

**Workshop-DIY Pi Core Learning Lab**

Full-service honeypot for intrusion detection. Simulates 6 service emulators with real-time attack monitoring.

## Features

- Real-time attack log with attacker IPs and attack types
- 6 emulated services: SSH, HTTP, FTP, Telnet, SMTP, MySQL
- Unique IP tracking and attack counters
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Deploy Honeypot**
3. Watch attacks arrive in real time
