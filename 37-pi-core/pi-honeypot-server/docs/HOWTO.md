# How-To: Pi Honeypot Server

## Getting Started

1. Open `index.html` in any modern browser.
2. Click **Deploy Honeypot** to start all service emulators.
3. Simulated attacks will begin arriving.

## Attack Monitor

- Shows attacker IP, target port/service, and attack type.
- Color-coded entries in red for immediate visibility.

## Service Emulators

- Lists all 6 emulated services with their port numbers.
- Each service tracks its own attack count.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
