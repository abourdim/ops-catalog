# 📡 Pi Repeater

**Workshop-DIY Pi Core Learning Lab**

Software-defined radio repeater controller. Simulates a full repeater with TX/RX monitoring, CTCSS, auto-ID, and frequency management.

## Features

- RX/TX frequency display with CTCSS tone
- Real-time TX/RX level meters
- Repeater state monitoring (IDLE/TX)
- TX timer and CW ID sender
- Configuration panel with repeater parameters
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Enable Repeater**
3. Watch simulated traffic pass through the repeater
