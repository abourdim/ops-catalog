# How-To: Pi Repeater

## Getting Started

1. Open `index.html` in any modern browser.
2. Click **Enable Repeater** to start.
3. Simulated traffic will pass through the repeater.

## TX/RX Monitor

- Shows real-time activity with callsigns and signal levels.
- State indicator: IDLE (listening) or TX (retransmitting).

## CW ID

- Click **Send ID** to transmit Morse code station identification.
- Automatic ID occurs every 10 minutes per configuration.

## Settings

- Change language (EN/FR/AR) in Settings panel
- Switch between 8 visual themes
