# ⏰ Pi Clock Station

**Workshop-DIY Pi Core Learning Lab**

GPS-disciplined NTP time server. Real-time millisecond clock with satellite tracking, offset graph, and NTP client management.

## Features

- Large real-time clock with millisecond precision
- GPS satellite count and time offset tracking
- Offset accuracy graph canvas
- NTP client list with poll counts
- Trilingual UI (EN/FR/AR) with RTL support

## Quick Start

1. Open `index.html` in a browser
2. Click **Start NTP Server**
3. Watch clock accuracy and client polls
