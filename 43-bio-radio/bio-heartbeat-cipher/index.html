📚 A — How It Works
💓1

Heartbeat Sensing

micro:bit detects heartbeat via pulse sensor. Each beat's R-R interval is unique and unpredictable.

🔢2

R-R Extraction

Heart rate variability (HRV) provides true biological randomness from the autonomic nervous system.

🔑3

OTP Key Generation

R-R intervals are hashed and mixed to create one-time pad keys with high entropy.

🔒4

XOR Encryption

Message XOR key = ciphertext. The key is never reused, providing perfect secrecy.

🏆 C — Challenges
1

Entropy Test

Generate 10 keys. Are they all unique? Check by comparing hex strings.

2

Exercise Effect

Faster heartbeat = more or less entropy? Think about HRV changes during exercise.

3

Perfect Secrecy

Encrypt the same message twice with different keys. The ciphertexts should look completely different!

Pro Tips

Did You Know?

Common Mistakes

🔑 One-Time Pad

Random key XOR message produces ciphertext. Proven unbreakable by Claude Shannon in 1949. Key must never be reused.

💓 Heart Rate Variability

HRV measures variation between consecutive heartbeats. Influenced by the autonomic nervous system, it contains genuine biological entropy.

⚡ XOR Cipher

XOR (exclusive or) flips bits using the key. Same operation encrypts and decrypts: plaintext XOR key = cipher, cipher XOR key = plaintext.
