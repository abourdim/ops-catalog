❓ Help
Can you control pupil dilation?

With training, some people can voluntarily dilate pupils by thinking of dark environments or emotional states.

What is the pupil size range?

Human pupils range from 2mm (bright light) to 8mm (darkness). Our threshold is set at 4.5mm.

How fast can you send Morse?

Experienced operators reach 5-10 WPM with pupil dilation. Traditional Morse can exceed 40 WPM.

👁 Pupillometry

Pupils dilate 2-8mm. Affected by light, emotion, cognitive load, and voluntary control.

💬 Morse Code

International Morse Code uses dots and dashes. Dot = 1 unit, Dash = 3 units, letter gap = 3 units, word gap = 7 units.
