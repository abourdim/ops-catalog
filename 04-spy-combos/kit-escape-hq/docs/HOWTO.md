# HOWTO — kit-escape-hq Workshop Guide

## Overview

This workshop runs a simulated spy escape room. Students solve 4 different puzzle types (cipher, pattern, sequence, logic) to unlock electromagnetic locks and escape before time runs out.

---

## Prerequisites

- A modern web browser
- No internet connection required

---

## Workshop Flow (30-45 minutes)

### Part 1: Introduction (5 min)
1. Open `index.html` in a browser
2. Explain the concept: "You are locked in spy HQ. Solve 4 puzzles to unlock the door."
3. Open Section A to review escape instructions
4. Open Section B to learn about each puzzle type

### Part 2: Start the Escape (2 min)
1. Click **Start Escape** to begin the 10-minute timer
2. Point out the room map, lock indicators, and inventory

### Part 3: Solve Puzzles (20-30 min)
1. **Cipher Lock** — Click the cipher card. Read the encrypted letters and shift value. Decode by shifting each letter back. Type the answer.
2. **Pattern Grid** — Click the pattern card. Watch the pattern flash on the 4x4 grid. Recreate it by clicking cells. Click Check Pattern.
3. **Sequence Key** — Click the sequence card. Find the pattern in the numbers. Type the missing number.
4. **Logic Gate** — Click the logic card. Read the logic expression. Click TRUE or FALSE.

### Part 4: Escape! (2 min)
- When all 4 puzzles are solved, all locks turn green
- The door on the room map changes from red (LOCKED) to green (OPEN)
- Escape time is logged

### Part 5: Challenges (Optional, 10 min)
1. Open Section C
2. Try Speed Escape (auto-solve with random time)
3. Try Hardcore Mode (see harder difficulty settings)

---

## Key Learning Points

1. Caesar cipher teaches basic substitution encryption
2. Pattern recognition trains visual memory
3. Number sequences develop mathematical thinking
4. Logic gates are the foundation of all computing
5. Time pressure simulates real-world problem solving
