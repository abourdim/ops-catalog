# kit-escape-hq — Workshop DIY

**Solve puzzles with ESP32 locks and micro:bit gadgets — spy escape room simulation**

---

## What It Teaches

- **Caesar Cipher** — Classical substitution encryption
- **Pattern Recognition** — Visual memory and spatial awareness
- **Number Sequences** — Mathematical pattern analysis
- **Logic Gates** — AND, OR, NOT, XOR — fundamentals of digital circuits
- **Problem Solving** — Working under time pressure

## Features

### Main Card
- **Room Map Canvas** — Visual room layout with puzzle locations, door status
- **4 Puzzle Cards** — Cipher Lock, Pattern Grid, Sequence Key, Logic Gate
- **Lock Status** — 4 lock indicators (locked/unlocked)
- **Puzzle Workspaces** — Interactive solving areas for each puzzle type
- **Inventory** — 6-slot inventory that fills as puzzles are solved
- **Countdown Timer** — 10-minute escape timer with critical-time warning

### Section A — How To Escape
### Section B — Puzzle Encyclopedia
### Section C — Speed Challenges (Speed Escape, Hardcore Mode, Leaderboard)
