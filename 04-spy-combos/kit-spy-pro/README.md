# kit-spy-pro — Workshop DIY

**micro:bit wearable + ESP32 field device + browser HQ — full spy loadout simulation**

---

## What It Teaches

Spy Kit Pro simulates a 3-device spy system. Students learn about:

- **IoT Device Networks** — How wearables, field sensors, and HQ communicate
- **BLE & MQTT** — Bluetooth Low Energy and MQTT protocols for IoT
- **Encrypted Communications** — AES-256 simulation for secure messaging
- **Mission Coordination** — Real-time telemetry and agent tracking

## Features

### Main Card
- **3-Panel Dashboard** — Wearable status (HR, steps, battery), Field device (signal, temp, battery), HQ Map (canvas with grid, agents)
- **Mission Selector** — Recon, Intercept, Extraction missions with step-by-step simulation
- **Encrypted Comms** — Send/receive messages with ROT13 encryption display
- **Device Connect** — Simulated BLE/MQTT connection sequence
