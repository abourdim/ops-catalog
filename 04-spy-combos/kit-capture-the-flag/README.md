# kit-capture-the-flag — Workshop DIY

**ESP32s broadcast clues, teams compete — physical capture the flag simulation**

---

## What It Teaches

- **CTF Competitions** — How capture-the-flag games work
- **BLE Beacons** — ESP32 devices broadcasting clues wirelessly
- **Ciphers & Decoding** — Simple encryption used to hide flag codes
- **Teamwork** — Red vs Blue team competition and strategy

## Features

### Main Card
- **Game Timer** — 5-minute countdown with large Orbitron display
- **Scoreboard** — Red vs Blue with scores and flag counts
- **Team Selector** — Join Red or Blue team
- **Clue Scanner** — Simulated ESP32 beacon scanning
- **Flag Submission** — Enter FLAG{XXXX} codes to score

### Section A — Game Rules
### Section B — Live Game Feed
### Section C — Bonus Challenges (Speed Run, Cipher Flag, Hidden Beacon)
