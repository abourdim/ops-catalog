📚 Game Rules
1️⃣ Teams

Two teams: Red and Blue. Each player joins one team. Teams work together to find and capture flags.

2️⃣ Clues

ESP32 beacons are hidden around the play area. Each beacon broadcasts encrypted clues via BLE. Use the scanner to receive and decode them.

3️⃣ Flags

Each clue leads to a flag code (format: FLAG{XXXX}). Enter the code to capture the flag. Each flag is worth points. First team to submit a flag gets bonus points.

4️⃣ Winning

Game lasts 5 minutes. The team with the most points when time runs out wins. Flags: 100 pts. First capture bonus: 50 pts. Speed bonus: up to 25 pts.

Simple encryption methods used to encode clues. Teams must decode them to find the flag.
