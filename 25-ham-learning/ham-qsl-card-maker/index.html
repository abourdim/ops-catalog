❓ Help
What does this app do?

It simulates ham radio! 🔬 You get to experiment with radio signals in a safe sandbox.

How does it work?

The simulation runs in your browser. It models real radio signals so you can see what happens step by step.

What should I try first?

Press the main button and watch! 🎯 Then tweak the settings to see how different parameters change the results.

What's the real science?

This is real amateur radio communication! The same principles are used by professionals in the field. 🧪

Can I break it?

Try the Lab section! Push the parameters to extremes and see what happens. That's how scientists discover new things! 💡

What hardware do I need?

For the real version, you'll need a computer with Python 3. Check the 📦 Device Code section for ready-to-use firmware!

Is it safe to use?

Absolutely safe! 🛡️ Everything runs locally in your browser. No internet required, no data leaves your device.

What should I try next?

Try Ham Band Condition Game and Ham Antenna Sim Vs Real! Each teaches something different. 🚀
