❓ Help
What is CW Paddle?

A virtual Morse code paddle simulator. Tap DIT and DAH to send dots and dashes, and the app decodes them in real time.

How do I send a letter?

Press DIT for a short tone (dot) and DAH for a long tone (dash). Combine them to form letters — for example, A is DIT-DAH (.- ).

What is WPM?

WPM stands for Words Per Minute. It controls the speed of Morse code timing. Beginners should start at 5-10 WPM.

Can I change the tone?

Yes! Use the Tone slider to adjust the frequency between 400 Hz and 1000 Hz. The classic CW tone is around 700 Hz.

🔑 Morse Code

Morse code encodes text as sequences of dots (short) and dashes (long). Invented by Samuel Morse in the 1830s, it remains vital in amateur radio.

📡 CW Operation

CW (Continuous Wave) is the original radio communication mode. Operators use a key or paddle to transmit Morse code over radio frequencies.

⏱️ Timing Rules

DIT = 1 unit, DAH = 3 units, intra-character gap = 1 unit, inter-character gap = 3 units, word gap = 7 units.

📻 Ham Radio Basics

Amateur (ham) radio is a hobby using radio frequencies for communication, experimentation, and emergency services. CW is one of its oldest modes.
