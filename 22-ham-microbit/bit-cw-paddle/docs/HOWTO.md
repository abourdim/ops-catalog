# HOWTO — bit-cw-paddle

## Getting Started

1. **Open the app** — Load `index.html` in Chrome, Firefox, Safari, or Edge.
2. **Wait for splash** — The Workshop-DIY splash screen appears briefly. Tap to skip.
3. **Enable sound** — Open Settings (gear icon) and toggle Sound effects ON to hear Morse tones.

---

## Sending Morse Code

### Using Paddle Buttons
- Press **DIT** for a short tone (dot `.`)
- Press **DAH** for a long tone (dash `-`)
- Combine them to form letters (e.g., `.-` = A, `-...` = B)

### Using Keyboard
- Press **`.`** or **Left Arrow** for DIT
- Press **`-`** or **Right Arrow** for DAH

### Timing
- After you stop pressing, the app waits **3 DIT lengths** then decodes the letter
- After a longer pause (**7 DIT lengths**), a word space is added

---

## Adjusting Speed

1. Find the **Speed (WPM)** slider in the main card
2. Drag left for slower (5 WPM = beginner), right for faster (30 WPM = advanced)
3. WPM controls both playback speed and decoding sensitivity

---

## Adjusting Tone

1. Find the **Tone (Hz)** slider in the main card
2. Drag to set the frequency from 400 Hz (low) to 1000 Hz (high)
3. The classic CW sidetone is around 600-700 Hz

---

## Playing a Message

1. Type text in the **Play a Message** input field (e.g., `SOS` or `HELLO`)
2. Press **Play** to hear and see the message played in Morse code
3. The decoder shows each letter as it plays

---

## Practice Mode

1. A random letter or number appears in large text
2. Key it using DIT/DAH buttons
3. Press **Check** to verify your answer
4. Press **New Letter** for the next challenge
5. Press **Clear** to reset the Morse display

---

## Section A: How It Works

Expand this section to learn the 4 fundamental timing rules:
- DIT = short tone (1 time unit)
- DAH = long tone (3 time units)
- Letter gap = 3 time units of silence
- Word gap = 7 time units of silence

---

## Section B: Lab Activities

1. **Letter Practice** — Work through each letter of the alphabet
2. **Decode Incoming** — Use Play Message to send yourself Morse, then decode by ear
3. **Speed Test** — Set a timer, see how many letters you can key correctly

---

## Section C: Challenges

1. **SOS Challenge** — Send `... --- ...` using the paddle buttons
2. **Decode Challenge** — Set speed to 15 WPM, play a secret word, decode it
3. **Name Challenge** — Key your full name in Morse without any mistakes

---

## Changing Language

1. Open **Settings** (gear icon in header)
2. Select **EN** (English), **FR** (French), or **AR** (Arabic)
3. Arabic automatically enables right-to-left layout

---

## Changing Theme

1. Open **Settings** (gear icon)
2. Choose from 8 themes: Mosque Gold, Zellige, Andalus, Riad, Medina, Space, Jungle, Robot

---

## Tips

- Start at **5-10 WPM** and increase speed as you improve
- Learn the most common letters first: E, T, A, I, N, S
- SOS (`... --- ...`) is the most famous Morse code signal
- Use the Activity Log to track your keying history
- Practice daily for 10-15 minutes for best results
