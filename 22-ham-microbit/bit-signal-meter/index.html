🔐 How It Works
1

The antenna picks up a radio signal from the air. The signal strength depends on transmitter power, distance, and obstacles.

2

An ADC (analog-to-digital converter) measures the voltage from the receiver, converting the analog signal to a digital number.

3

The digital value is converted to dBm and then to S-units. Each S-unit equals 6 dB. S9 = -73 dBm.

4

The LED matrix displays a bar graph: columns fill from bottom to top based on signal strength, giving a visual S-meter.

🧪 Lab
1

Map signal strength to LED patterns: adjust the signal slider and observe how the bar graph fills columns from left to right.

2

Calibrate the S-meter: compare the dBm value with the S-unit reading. Verify that each S-unit step equals 6 dB.

3

Measure SNR: adjust the noise floor slider and observe how the signal-to-noise ratio changes. A higher SNR means a cleaner signal.

4

Compare analog vs digital meter: watch how the LED bar graph approximates a traditional analog S-meter needle movement.

🏆 Challenge
1

Design a custom LED pattern for each S-level: create unique visual patterns for S1, S5, and S9 that go beyond simple bar graphs.

2

Find the signal in the noise: set a high noise floor and slowly adjust the signal level. At what SNR can you first detect the signal on the display?

3

Build a peak-hold meter: modify the display so the highest signal level is remembered and shown as a single bright LED above the current bar.

❓ Help
What is this app?

A Workshop-DIY signal meter simulation. It teaches radio signal measurement using a micro:bit-style 5x5 LED matrix.

What is an S-meter?

An S-meter displays received signal strength in S-units (S1 to S9, then S9+dB). Each S-unit represents 6 dB of signal change.

How do I read the LED bar graph?

Columns light up left to right. More lit columns mean a stronger signal. The height of each column shows fine-grained level.

Is my data private?

Yes. Everything runs locally in your browser. No data is sent anywhere.

📶 S-Meter Scale

S1=-121 dBm, S2=-115 dBm... S9=-73 dBm. Above S9, readings are S9+10, S9+20, etc. Each S-unit = 6 dB.

📊 dB and dBm

dB is a ratio (relative). dBm is power relative to 1 milliwatt (absolute). -73 dBm = S9 by convention.

📉 Signal-to-Noise Ratio

SNR = signal level minus noise floor in dB. Higher SNR means cleaner reception. Below ~6 dB SNR, signals become hard to decode.

💡 LED Matrix Programming

The micro:bit has a 5x5 LED matrix (25 LEDs). Each LED can be on/off or have brightness levels 0-9. Bar graphs use columns as signal indicators.
