📶 S-Meter Scale

S1=-121 dBm, S2=-115 dBm... S9=-73 dBm. Above S9, readings are S9+10, S9+20, etc. Each S-unit = 6 dB.

📊 dB and dBm

dB is a ratio (relative). dBm is power relative to 1 milliwatt (absolute). -73 dBm = S9 by convention.

📉 Signal-to-Noise Ratio

SNR = signal level minus noise floor in dB. Higher SNR means cleaner reception. Below ~6 dB SNR, signals become hard to decode.

💡 LED Matrix Programming

The micro:bit has a 5x5 LED matrix (25 LEDs). Each LED can be on/off or have brightness levels 0-9. Bar graphs use columns as signal indicators.
