🎓 How It Works

Every 802.11 frame begins with a Frame Control field (2 bytes) that identifies the frame type and subtype. The Duration field (2 bytes) reserves airtime. Three MAC addresses follow: Destination (Addr1), Source (Addr2), and BSSID (Addr3). The Sequence Control field tracks frame ordering. The body contains the payload, and the FCS (Frame Check Sequence) provides error detection. This simulation generates realistic frames and color-codes each field for easy identification.
