# WiFi Timeline — Event Reconstructor

**Reconstruct WiFi events on an interactive timeline canvas with color-coded markers.**

## Features
- Interactive timeline canvas with event markers (6 types, 6 colors)
- Hover-to-inspect event details on canvas
- Chronological event log with type badges
- Event distribution chart with percentages
- Statistics: total events, per-type counts
- Full i18n: EN/FR/AR, 8 themes, help panel, activity log

## Quick Start
Open `index.html` and click **Record** to start the timeline simulation.
