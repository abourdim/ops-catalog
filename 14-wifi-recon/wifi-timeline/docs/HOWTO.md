# How-To Guide — WiFi Timeline

## Overview
Reconstructs WiFi events on a chronological timeline canvas for forensic analysis.

## Steps
1. Open `index.html` in a browser
2. Click **Record** to start capturing events
3. Watch colored dots appear on the timeline canvas (each row = event type)
4. Hover over dots to see event details
5. Check **Event Log** for a chronological list
6. View **Event Distribution** for type breakdown with percentages

## Tips
- Each horizontal band represents a different event type (beacon, probe, auth, deauth, data, assoc)
- Deauth clusters (red dots) indicate potential attacks
- The distribution chart helps identify unusual event patterns
- Export the activity log for offline forensic analysis
