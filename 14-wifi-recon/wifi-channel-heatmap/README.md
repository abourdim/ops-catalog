# Channel Heatmap — Congestion Map

**14-channel WiFi congestion heatmap with signal analysis and AP listing.**

## Features
- Color-coded heatmap grid (green/yellow/red) for all 14 channels
- Signal strength bar chart
- AP list by channel with SSID, MAC, signal
- Clickable channel cells for detailed info
- Statistics: total APs, busiest/freest channel, average signal
- Full i18n: EN/FR/AR, 8 themes, help panel, activity log

## Quick Start
Open `index.html` and click **Scan** to start the heatmap simulation.
