# Beacon Flood — AP Visualizer

**Simulates a beacon flood attack showing fake APs, channel distribution, and hidden networks.**

## Features
- Rapid fake AP generation with SSID, MAC, channel, signal, encryption
- Channel distribution bar chart (13 channels)
- Hidden network detection and listing
- Statistics: total APs, hidden count, beacon rate, active channels
- Full i18n: English, French, Arabic (RTL) / 8 themes

## Quick Start
Open `index.html` and click **Start** to watch the flood simulation.
