🎓 How It Works

An evil twin is a rogue access point that copies the SSID of a legitimate network to trick users into connecting. While the SSID matches, other attributes often differ — MAC address, channel, encryption type, signal strength, and beacon interval. By comparing these attributes between APs with the same SSID, we can detect potential evil twins. This simulation generates legitimate APs and occasionally introduces evil twins with subtle mismatches for you to identify.
