🛡️ Faraday Cages

Named after Michael Faraday, these enclosures block EM fields using conductive mesh or solid metal shells.

📊 Shielding Effectiveness

SE = 20 log10(Ei/Et) in dB. Higher values mean better shielding. 30 dB is good, 60+ dB is excellent.

📡 RF Frequencies

Radio frequencies range from 3 kHz to 300 GHz. WiFi uses 2.4/5 GHz, Bluetooth 2.4 GHz, LoRa 433/868/915 MHz.
