What is the Agent Communicator?

A Pi-based encrypted messaging system using numbers station protocols and one-time pad encryption for unbreakable communications.

What is a numbers station?

A shortwave radio station that broadcasts sequences of numbers encoding secret messages. Used by intelligence agencies worldwide since the Cold War.

What is one-time pad encryption?

The only theoretically unbreakable cipher. Each character is encrypted with a unique random key that is never reused. The key must be as long as the message.

What does Burn Keys do?

Permanently destroys all encryption keys in memory, making all previously sent messages impossible to decrypt even with full system access.
